# 幸福里租金试点

现有“采集租金”入口已支持已确认的幸福里关联，其他小区继续走房天下。两个来源不会在同一个小区中混算。没有启用自动搜索：`full_text` 搜索的 HTTP 200 可能返回全市推荐。

## 部署后启用

先在实际数据目录做只读预览：

```sh
python scripts/import_xingfuli_pilots.py --data-dir /app/data
```

仅 `ready` 行可以导入，`unverified` 不会强绑，`protected` 表示已有人工决定。当前两条研究来源是风雅钱塘、欣盛东方郡，但是否可用以现有住宅资格、唯一名称以及地址/位置证据为准。2026-10-23 NAS 只读核查显示东方郡符合当前资格，风雅钱塘不符合；不要改变目录资格来凑试点。

审阅预览后，停止后台服务和其他目录/租金写入者，在相同镜像的一次性维护容器中执行：

```sh
python scripts/import_xingfuli_pilots.py --data-dir /app/data --apply --maintenance
```

恢复服务后使用原有“采集租金”入口。首次需要逐条核验整租详情，每次HTTP间隔至少5秒，耗时可能数分钟。没有自动写入生产或启动定时任务。

## 失败与回退

来源被拦或分页/详情不完整时保留同来源旧快照，采集日期不刷新。种子房源下架不能误报暂无房源。解除幸福里关联后，若原房天下关联仍有效，下次选择房天下；旧幸福里快照不能充当房天下数据。试点导入重跑不会恢复已经解除或忽略的关系。

租金是挂牌租金；列表整租标记数不是合格统计样本数，合租、分割疑似、重复、未核验详情仍按原规则剔除。
