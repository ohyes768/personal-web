```

**After**（对齐到 240px 视觉重心）
```
┌─────────────────────────────────────────┐
│ 📚 合集 · 12 项      ✓ 已安装 12/12      │  ← 顶部 status
│ ai-berkshire                              │
│ xbtlinx/ai-berkshire                      │

│ era-alpha、financial-data、management-   │  ← member 预览

└─────────────────────────────────────────┘
  高度 ≈ 240px（与独立卡平衡）

新加的 state chips 行：
- 📦 已导出 N 目标（export records 统计）
- 🆕 有更新 N 项
- ⚠ 异常 N 项

**关键**：
- 把原本只在成员展开后才看到的 state 信息提到折叠卡可见
- 加「✓ 完成态」强化 12/12 的成就感
- 高度对齐独立卡，grid 不再有"高瘦混合"问题

## 🔴 1C. 合集展开后加批量主操作

**Before**（现状 toolbar）
```
┌──────────────────────────────────────────────────────────┐
│ 全选  清空  已选 0 项           下载合集 +添加成员 检查更新  安装所选(0) │
└──────────────────────────────────────────────────────────┘
   6 个控件挤在一行，"安装所选"视觉权重 = 跟次级操作一样
```

**After**（主次分明）
```
┌──────────────────────────────────────────────────────────┐
│ 全选  清空  已选 0 项                                        │
│                                              [更新整个] [下架整个]    │
│                                              下载合集 +添加成员 检查更新 │
│                                              ━━━━━━━━━━━━━━━━━━━━ │
│                                              [   安装所选 (0)   ]      │  ← 主按钮，filled sky
└──────────────────────────────────────────────────────────┘
左半：选择操作（永远在左）
右半：合集管理操作（顶部一行：批量主操作） + 次级操作 + 主操作

主按钮样式对比：
- 安装所选：bg-sky-600 text-white filled     ← 当前主操作
- 更新整个：border-sky-300 text-sky-700 outline  ← 新增次级主
- 下架整个：border-rose-300 text-rose-700 outline  ← 新增次级主
```

**关键**：
- 「更新整个合集」「下架整个合集」作为次级主按钮补齐
- 视觉权重：filled = 主 > outline = 次级主 > ghost = 次级
- 用户一眼看出"主路径是安装所选"，批量主操作是备选

## 🥈 2A. 统一状态指示器（独立卡 + 合集卡共用）

**现状**：状态散落 4 处（标题旁 / 卡片底部红字 / 卡片底部琥珀条 / tooltip）

**After**：标题旁一个紧凑 chip

```
可装（默认）：
  [已安装 ✓] [有更新]   ← 绿 / 琥珀

待 Clone：
  [需 Clone]            ← 琥珀

源缺失：
  [源缺失]              ← 红

目标不可用：
  [目标不可用]           ← 灰
```

```
示例：impeccable 卡（pbakaus/impeccable，未安装但有更新）
┌─────────────────────────────────────────┐
│ impeccable                  🆕 有更新   │  ← 标题旁 chip 统一指示
│ pbakaus/impeccable                       │
│ ...summary...                            │
└─────────────────────────────────────────┘
```

**关键**：
- 4 种状态→4 种 chip，统一尺寸/位置/字体
- 取代卡片底部的「缓存缺失」独立红字条
- 取代 install 按钮 tooltip 里的不可用说明
- 一眼分辨"能不能装"

## 🥉 3B. filter bar 简化

**Before**：
```
┌──────────────────────────────────────────────────────────┐
│ 🔍 按仓库/名称/ID/简介搜索   [全部 ▾] [更新:全部 ▾]      │
│ [投研] [ai伯克希尔] [UI]                                  │
└──────────────────────────────────────────────────────────┘
```
4 个控件挤在一行；窄屏必折行

**After**：
```
┌──────────────────────────────────────────────────────────┐
│ 🔍 按仓库/名称/ID/简介搜索         [筛选 (3) ▾]          │
└──────────────────────────────────────────────────────────┘
筛选 popover 收纳：安装状态 + 更新状态 + 已选 tag chips
激活筛选时 chip 显形，未激活时折叠到 popover
```

**关键**：
- 主行只有搜索框 + "筛选(N)" 按钮
- popover 内显示当前激活的筛选条件 + 可编辑控件
- 窄屏友好
- 移动端省行

## 决策矩阵

| 优先级 | 收益 | 风险 | 推荐 |
|---|---|---|---|
| 1A | 高（30px × N 卡） | 低（纯展示） | ✅ 必做 |
| 1B | 高（视觉平衡） | 中（要算 export 统计） | ✅ 必做 |
| 1C | 高（补缺失主路径） | 中（要权限/确认） | ✅ 必做 |
| 2A | 高（解决状态散落） | 中（要迁移 tooltip 提示） | ✅ 推荐 |
| 2B | 中（export 视觉层级） | 低 | ✅ 推荐 |
| 2C | 中（完成感） | 低 | ⭕ 可选 |
| 3A | 中（28px 节省） | 低 | ⭕ 可选 |
| 3B | 中（窄屏体验） | 中（filter 组件重写） | ⭕ 单独 sprint |

**我的建议**：先做 1A + 1B + 1C（合集三件套），解决最痛点；2A + 2B 跟进；3A / 3B 看反馈再决定。
