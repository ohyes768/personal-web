## 2. URL 规律

```
/zhengcehuobisi/125207/125213/125431/<code>/<YYYYMMDD + 10位数字>/index.html
```

示例(`/125475/`):
```
/zhengcehuobisi/125207/125213/125431/125475/2026083108481886588/index.html
                ^^^^^^^^^^^^^固定 ^^^^^         ^^^^^^^^^^^^^^^^^^^^^^^^^^
                货币政策司 > 公开市场业务           20260831 = 公告日期
```

- 日期 = URL 第二段的前 8 位
- 后 10 位是央行内部的递增 ID,**无需解析**
- 列表页(`/125475/index.html`)一次返回最近 20 条,带「下一页」翻页

## 3. 公告页结构(以 125475 为例)

页面只有 1 个表格 + 几段正文,**结构稳定**:

```html
<div id="article"> <!-- 或 content / zoom -->
  <h2>公开市场业务交易公告 [2026]第169号</h2>
  <!-- 1 段开场白 + 1 个 N 行表格 -->
  <p>2026年8月31日中国人民银行以固定利率、数量招标方式开展了50亿元7天期逆回购操作，全额满足了一级交易商需求。具体情况如下：</p>
  <table>
    <tr><th>期限</th><th>操作利率</th><th>投标量</th><th>中标量</th></tr>
    <tr><td>7 天</td><td>1.40%</td><td>50 亿元</td><td>50 亿元</td></tr>
  </table>
  <p>同时，开展了4470亿元隔夜逆回购操作。</p>
</div>
```

**解析口径**(中文 OMO 公告标准模板):
- 「开展 X 亿元 N 天期逆回购操作」→ 投放量 X,期限 N 天
- 「投标量 = 中标量」表示**全额中标**(常见)
- 「同时,开展了 X 亿元隔夜逆回购操作」→ 隔夜投放,**常常没有单独表格**
- 利率偶尔会缺失(2024 年起多为「固定利率、数量招标」,利率字段常省略)

## 4. 净投放 / 到期量 — 本地计算(公告不含)

央行公告**只公布当日投放量**。净投放、到期量必须本地用历史数据滚动算出。

### 当日到期量(同期限对应)

```
当日 N 天期到期量 = N 个交易日前那天的「N 天期逆回购中标量」
当日隔夜到期量   = 前 1 个交易日的「隔夜逆回购中标量」
```

### 当日净投放

```
净投放 = Σ 当日各期限投放量 − Σ 当日各期限到期量
```

### 累计窗口

- **DR007 利差** = DR007 − 7 天逆回购政策利率(OMO 利率从公告拿)
- **滚动净投放**:5 / 10 / 20 个交易日窗口,常用于评估资金面松紧
- **季节性扰动**:月末 / 季末 / 跨年央行会加大投放,只看日频会被噪音盖住

## 5. 反爬与稳定性

实测信息(curl + Mozilla UA 一次即 200 OK):

- `Server: nginx` + 多级 CDN(`x-via` 头可见 `PS-TAO-01` / `PS-NZG-014` / `PS-WNZ-01` 串行)
- `Last-Modified` 和 `ETag` **都齐**,**必须用 `If-Modified-Since` / `If-None-Match`**,传输可省 90%
- 无验证码、无 cookie 要求、无 JS 渲染
- 高频抓(分钟级)会被 CDN 限速,建议:**工作日 09:30 / 16:30 各 1 次**(对应央行早盘/午盘公告);周末/节假日不抓
- 加 1-3 s 随机延时 + 失败指数退避

## 6. 三个隐藏坑

1. **交易日 vs 自然日**:周末/节假日无逆回购,但**到期照样发生**(顺延到下一交易日)。「7 个交易日前」必须按交易日历算,不然春节、国庆那周全错。需要维护一份中国交易日历(可从 akshare `tool_trade_date_hist_sina()` 拿)。
2. **合并发布**:节后第一天央行常把假期内几天的公告合并成一条发布,正文中会写「2 月 X 日至 Y 日开展了…」,爬虫**不能盲信「最新一条 = 当天」**,必须按日期去重并解析正文里的多日期。
3. **隔夜跨周末**:周五的隔夜顺延到周一到期(= 3 天后才到期),节假日同理。「隔夜到期量」算的是**自然日**,但匹配的是**交易日窗口**,这两套口径别混。

## 7. 数据 Schema 建议(供后续任务参考)

```sql
CREATE TABLE omo_announcement (
    date           DATE PRIMARY KEY,        -- 公告日期(从 URL 取)
    url            TEXT NOT NULL,
    title          TEXT,                    -- 例「公开市场业务交易公告 [2026]第169号」
    fetched_at     TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    raw_html_path  TEXT                     -- 原始 HTML 缓存路径(便于回溯)
);

CREATE TABLE omo_operation (
    date           DATE NOT NULL,
    term_days      INTEGER NOT NULL,        -- 1=隔夜, 7=7 天, ...
    op_type        TEXT NOT NULL,           -- 'reverse_repo' | 'mlf' | 'psl' | ...
    amount_yi      NUMERIC(10,2) NOT NULL,  -- 亿元
    rate_pct       NUMERIC(5,3),            -- 利率 %;固定利率招标可能为 NULL
    bid_amount_yi  NUMERIC(10,2),           -- 投标量;隔夜常缺
    PRIMARY KEY (date, term_days, op_type),
    FOREIGN KEY (date) REFERENCES omo_announcement(date)
);
CREATE INDEX omo_op_date_term ON omo_operation(date, term_days);
-- ↑ 这是到期量滚动查询的关键索引
```
