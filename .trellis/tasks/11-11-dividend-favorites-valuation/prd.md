# Dividend 收藏跟踪与 Hermes 四挡位评估

## Goal

将挡位监控 Tab 替换为收藏跟踪，展示全部收藏股；接入 Hermes 四挡位评估、报告确认和监控；价格条收窄为四阈值五区间，未评估不显示。

## Requirements

- R1：原「挡位监控」Tab 改为「收藏跟踪」，展示全部收藏，不限于已配置挡位的股票。提供全部收藏、待评估、待应用、监控中、已暂停筛选和名称/代码搜索。
- R2：收藏跟踪提供逐股「评估挡位」及重评入口；选股关注收藏成功后提供快捷评估按钮。收藏不自动提交评估，也不自动开启监控。
- R3：通过 Hermes 调用 `stock-four-level-valuation`，复用基本面材料及其期间，展示排队、执行中、成功、失败与重试。估值任务与基本面任务分开表达；不将质量分映射为价格。
- R4：处理 ready / insufficient_data / blocked / not_applicable 四类结果，非 ready 可阅读原因但不可应用。首次有效报告由用户确认后保存挡位并开启监控。
- R5：重评保留旧生效挡位和启停状态，新报告可对比后应用；失败、资料不足或暂不应用不覆盖旧配置。支持暂停/恢复监控。待应用可以与监控中或已暂停重叠。
- R6：价格图比已认可原型更窄，参考宽度 220–260px；四个递增阈值（重仓、加仓、减仓、全卖）分隔五个价格区间，加横条、四价标签及现价标记。超出两端和缺少现价均需有明确表达。
- R7：未评估不画价格条；没有历史有效挡位的评估中、失败或非 ready 不画虚构价格或空五块图。首次 ready 尚未应用时可显示明确标注「评估结果 · 未启用监控」的预览；有旧生效配置时列表继续显示旧条，新值在报告中对比。
- R8：沿用现有暖白配色和紧凑表格；桌面和窄屏均能操作。保留旧 alerts URL、历史收藏及监控配置，不自动迁移价格或启用提醒。

## Acceptance Criteria

- [ ] AC1 / R1：新收藏和旧监控股票均可见，五种筛选及搜索可用，重叠筛选计数语义清晰。
- [ ] AC2 / R2–R3：两处评估入口提交正确股票，异步状态、重复提交处理及失败重试正常；刷新后可恢复任务/结果。
- [ ] AC3 / R3–R4：真实 skill 输出校验、身份、期间、模型与来源信息保留；非 ready 不生成可应用价格，不以星级或现价固定比例定价。
- [ ] AC4 / R4–R5：首次报告确认后才开启监控；重评可对比新旧，失败和未应用不影响旧监控，暂停/恢复可持久化。
- [ ] AC5 / R6–R7：图条是四阈值五区间，未评估隐藏，候选与生效语义不同；条宽较原型缩小，现价越界和缺失不误导。
- [ ] AC6 / R8：旧 URL、旧收藏和手工挡位仍可用；桌面/窄屏主操作可达，无页面整体横向溢出。

## Background and constraints

- 基本面分析已通过 Hermes 调用 basic-quality-rating；收藏没有评级通过门槛，不等同于用户已认可或已持仓。
- 现有 favorites/alerts 已支持四价保存、启停监控及通知；估值 skill 只输出 JSON，不访问平台或回写，应用职责属于 dividend。
- Skill 源：`F:/personal-projects/skills/investment-analysis/stock-four-level-valuation`，实现前需核实 Hermes 实际部署版本。
- 用户已认可的交互原型归档为 `prototype.html`。原型仅示意布局/交互，虚构数据、定时完成及按现价比例生成价格的模拟代码不可作为生产实现。
- 用户最新要求：“挡位图可以窄一点”“4挡位/5块加个条”“没评估的先不显示”。本任务将五块解释为四阈值分隔五区间。

## Out of scope

自动交易、实际持仓管理、个性化仓位建议；收藏即自动评估；新结果自动覆盖监控；本次登记阶段修改生产代码或执行真实研究任务。
