# 信号首页月度卡压密度

## Goal

双区块结构不变，把月度卡从「每指标两行 + 大 padding」压成一眼能看完 4 张月度 + 3 张日频，减少滚动。

## 背景

已选方案 **A**：不改左右分栏、不默认收起卡片。高度主要来自月度行的「数据 / 分析 / 下次」第二行，以及卡内 `p-5`、行 `py-2`、区块 `space-y-8`。

## Requirements

### R1 月度指标一行

- 默认只显示名称（+ 📈）和数值
- 数据日、分析时间、下次发布、月均/日频说明合并进该行 `title` 悬停
- 占位（暂未获取）仍显示数值 `—`，详情在 title
- 数据偏旧：名称用黄色，title 含「数据偏旧」
- 整行可点逻辑不变

### R2 收紧间距

- 月度/日频卡片 `p-5` → `p-3`，卡头与列表间距缩小
- 指标行 `py-2` → `py-1`，数值 `text-lg` → `text-base`
- 区块间距 `space-y-8` → `space-y-5`，网格 `gap-4` → `gap-3`
- 档位刻度仍一整行，当前档可略缩小（`text-xl` → `text-lg`）但仍比其它档大
- 日频回退日期不占第二行，缩到名称旁或 title

## 约束

- 不改 2×2 月度 + 3 列日频的栅格
- 不改顶栏 Tab、数据接口、跳转映射
- 不默认折叠卡片

## 验收标准（Acceptance Criteria）

- [ ] **AC1** 月度指标行默认只有一行名称+数值；悬停能看到原数据/分析/下次信息
- [ ] **AC2** 占位指标仍为 `—`，悬停含暂未获取/预计发布
- [ ] **AC3** 偏旧指标名称可见黄色，悬停含「数据偏旧」
- [ ] **AC4** 日频卡仍可整行跳转；回退日不单独占一行
- [ ] **AC5** 桌面宽屏下月度 4 卡 + 日频 3 卡的总高度明显短于改前（无需为看日频先滚过一整屏元数据）

## 范围外

- 左右分栏（方案 B）
- 卡片默认收起（方案 C）
- 压缩顶栏 8 个 Tab
