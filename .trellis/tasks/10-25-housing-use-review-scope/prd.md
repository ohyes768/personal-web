# 高德用途自动复核范围收紧

用户已确认按讨论方案实施。

- 自动复核跳过人工用途决定/人工排除、明确非住宅、地址明确与目录区域冲突、尚未收录且仅标注“其他”的项目。
- 已收录住宅尚未完成定位时先补定位；缺失用途、用途冲突、公寓或商住等仍保留自动复核。
- 跳过只改变自动查询范围，不改变住宅准入，不抹除已有证据或人工决定；单项手动查询仍可用。
- 在目录与详情显示跳过原因，地址冲突明确提示区域异常；已有用途冲突仍保持醒目。
- 验收：批量请求仅覆盖目标项目；全部跳过不构造高德客户端；真实存储及 API 验证手动查询不受影响；前端验证跳过标签与冲突优先级。
