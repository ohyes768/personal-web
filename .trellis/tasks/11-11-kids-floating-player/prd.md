# kids-catalog 浏览器播放改为底部悬浮播放条

## 背景

设备歌单页的浏览器播放原来是「在触发行下方行内展开播放器」：每点一次播放，播放器就插在那一行下面，页面越往下越难找；想换合集还得先收起旧播放器。行内展开还带来过「同一合集在候选区和设备歌单表各渲染一个播放器、同一首音频重复出声」的坑。

用户诉求：做成**固定在最下方的悬浮播放器**。

## 需求

1. 播放条固定在视口底部（`position:fixed`），页面级单例：任意位置点「播放」都在同一条播放条里播放。
2. 播放条内容：合集名 + 曲目名 + 计数、原生 `<audio controls>`（暂停/进度/音量仍用浏览器原生控件）、上一首/下一首、曲目清单入口、收起。
3. 曲目清单改为**向上展开的抽屉**（`<details>`），可滚动，当前曲目高亮；点击仍能切歌。
4. 播放条不得遮挡页面内容（占位留白 `.player-spacer`），窄屏适配 iPhone 安全区 `env(safe-area-inset-bottom)`。
5. 仍不做跨页续播：切 tab / 离开页面即卸载停止（PRD 非目标不变）。

## 验收标准

- [x] 点任意合集的「播放」，底部出现唯一播放条，音频开始播放（Range 206）
- [x] 页面里始终只有 1 个 `<audio>` 实例（不再出现重复出声）
- [x] 上一首/下一首可用，首/末首按钮禁用；曲目抽屉向上展开、当前曲高亮、点击切歌可用
- [x] 桌面与 390px 均不出现页面级横向滚动；390px 抽屉不出屏幕边界
- [x] 切到「本月精选」tab 后播放条消失、音频停止
- [x] `pnpm exec tsc --noEmit` 通过；NAS 容器内 next build 通过
