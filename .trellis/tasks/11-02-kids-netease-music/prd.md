# Kid 支持网易云音乐链接下载与设备歌单

## 目标

在 kid 服务中补充网易云音乐来源，让用户通过歌单或专辑链接下载可用音频，并将下载结果纳入现有设备歌单选择与生成流程。

## 当前状态与授权边界

- 2026-11-02：用户确认上述接入范围，明确要求「创建 trellis 任务吧，先不用开发」。
- 本次仅登记任务和需求，保持 planning，不激活任务、不修改业务代码。
- 接口可用性尚未实测；后续需完成研究、技术设计和实施计划，待用户要求开发后再启动实现。

## 已确认的现状

- 后端为 `backend/kids-catalog`，前端为 `apps/kids-catalog`。
- `src/link_import.py` 当前负责喜马拉雅、蜻蜓专辑链接解析与可下载性预检。
- `src/downloader.py` 当前负责上述来源的曲目列表读取和音频下载；`src/main.py` 负责导入、下载任务及候选数据。
- 设备歌单使用已下载的本地音频和独立完成记录生成；无需为新增来源另建歌单生成系统，生成与编号查询也不依赖 MA。

## 需求

- R1：在现有手动导入入口支持网易云音乐歌单、专辑链接，读取集合名称与曲目列表；用户文案应说明新增支持的来源和链接类型。
- R2：下载平台允许获取的可用音频。对受限或没有可用音源的曲目逐条跳过，显示可理解的原因；网络或接口失败应如实报告，不能当作成功下载。
- R3：成功下载的内容复用现有目录、下载记录、完成确认和设备歌单候选流程，支持选择并生成设备歌单。
- R4：保留喜马拉雅、蜻蜓的现有导入与下载行为，兼容历史下载内容和已发布的设备歌单。

## 验收标准

- [ ] 网易云音乐歌单链接与专辑链接均可解析、读取集合名称与曲目；无效、空或不可访问集合有明确反馈。（R1）
- [ ] 可用音频实际下载落盘，并可被现有音频校验与歌单流程识别；受限、无音源、请求失败分别有准确结果。（R2、R3）
- [ ] 下载完成后能在现有设备歌单候选中选择，经现有确认流程生成歌单；生成失败仍保留旧发布快照。（R3、R4）
- [ ] 测试覆盖链接解析、集合读取、下载成功与失败/跳过，以及设备歌单衔接；喜马拉雅、蜻蜓相关回归检查通过。（R1—R4）
- [ ] 前端类型检查和生产构建通过，导入入口说明与错误提示符合实际支持范围。（R1、R4）

## 不在本期范围

- 将网易云音乐加入「本月精选」自动采集、儿童内容筛选或推荐排行。
- 新建网易云账户登录、会员或私人歌单同步功能，以及绕过付费或访问限制。
- 改造 MA、设备播放集成或既有设备歌单发布机制。

## 后续研究事项

- 核实当前可用的数据与音源接口、匿名访问边界、曲目分页完整性及限流行为，再确定实现方案；不将尚未验证的接口视为可用。
- 核实常见网页、移动分享、短链接的格式，确定首期明确支持的链接变体及安全解析方式。
- 验证音频格式、标签与本地集合标识方案；避免网易云歌单 ID 和专辑 ID 相同而发生身份冲突，保持重复导入幂等。
