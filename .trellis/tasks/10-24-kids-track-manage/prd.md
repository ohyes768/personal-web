# kids 已下载专辑曲目管理（弹窗查看/删除单曲）

## Goal

用户手动导入的专辑常是合集（例：《听，小蜗牛艾玛》18 曲，实际只要"完整版"一首）。
下载整张后需要能删掉多余的曲目，并有一个管理入口查看已下载的曲目清单。

## Requirements

1. **管理入口**：已下载（done / partial）的专辑卡片出现编辑入口，点击弹出弹窗。
2. **弹窗内容**：该专辑已下载的曲目列表（曲名、文件大小），每首一个删除按钮；
   删除即删本地文件，无需二次确认（可恢复，见 4）；弹窗内提示删除后可通过下载找回、
   已生成设备歌单的需重新生成。
3. **删除后的状态同步**（卡片徽章如实反映磁盘）：
   - 曲数徽章与大小徽章更新为剩余值（jobs.downloaded_tracks / size_bytes 同步）；
   - 剩余 >0：job 状态 → `partial`，reason 记录"用户删除曲目，剩余 N 首"；
   - 剩余 =0：删除 job 行，专辑回到 `not_downloaded`（卡片恢复"下载"按钮）。
4. **可恢复**：`partial` 状态的下载按钮改为可点（"补全下载"），`queue()` 的可重试集合
   加入 `partial`；重新下载时已存在文件自动跳过，只补回被删的曲目。
5. **安全与并发**：
   - 删除接口只接受纯文件名（无路径分隔符、限 .mp3/.m4a），防目录穿越；
   - 下载进行中（queued/running）拒绝删除，返回可读原因；
   - 专辑在完成台账（completions）中的记录在删除后失效（mark_failed），提示重新生成歌单。

## Out of Scope

- 导入时按曲目选择下载（列表须先请求平台接口，本期不做）；
- 已发布设备歌单的自动重建（现有生成流程已有 manifest 漂移检测，删除后重新生成即可）；
- 榜单侧逻辑不动。

## Acceptance Criteria

- [ ] `GET /api/albums/{id}/tracks` 返回已下载曲目（file/title/size，按文件名排序）；
      未下载返回空列表，404 仅当专辑不存在
- [ ] `DELETE /api/albums/{id}/tracks` 删除文件并同步 job（数量/大小/状态），台账失效
- [ ] 删除最后一首后专辑回到 not_downloaded，重新点下载能整张重下
- [ ] 剩余部分时状态 partial，卡片"补全下载"可点，重下只补缺的文件
- [ ] 非法文件名（路径穿越/错误后缀/不存在/下载中）分别返回 422/404/409 且不删任何文件
- [ ] 前端：卡片编辑入口 → 弹窗列表 → 删除后弹窗与卡片徽章即时更新
- [ ] `pytest -q` 全量通过；前端 tsc + 生产构建通过
