# 同地图展示新房项目并比较周边二手房

## 目标与状态

用户希望把新房与附近二手房放在同一张地图上比较，已选择“同地图＋房源类型切换”。本任务只创建规划，状态planning；尚未开始实现，不新增顶层新房tab。

## 背景

- 现有管理端CatalogFilters及DirectoryCards已有new_house/second_hand/unknown分类；地图Community类型和_assemble_community尚未完整投影市场身份与项目证据。
- BinjiangMap当前对无轮廓记录绘制100米问号方块，新房不适合沿用该表达或依赖建筑聚类。
- community-enrichment spec规定：在售/尾盘/待售有明确证据才归新房；售完按二手房；新房价格不能进入二手房指标；缺坐标不影响收录，但不能凭空上图；售楼处不得当项目所在地。

## 需求

### R1 共用地图与切换

地图增加“二手房／新房／全部”切换。规划默认全部，服务直接比较；切换不重置中心、缩放、搜索、区域、物业类型和配套图层。筛选后数量反映可见对象；切掉当前对象时清理其详情和临时图层。

市场状态未知者只在全部中显示，明确标“房源类型待核实”，不得默认为二手房。售完项目遵循已有有效市场状态转入二手房，无需删历史项目资料。

### R2 新房项目点

新房使用“新”徽标与项目名称，选中时突出，不用五角星。缩小时聚合/减少文字，放大可读。无轮廓正常展示项目点，不画问号方块、不提供建筑聚类生成入口。保留二手房现有轮廓与缺失提示。

### R3 地点可信度

展示实际项目所在地及已有来源、核验状态；核验点实心，符合既有上图资格的待核验位置空心且明示“位置待核实”。缺少合法项目坐标、仅售楼处坐标或存在位置冲突时不伪造项目点，保留管理端核对入口及未展示原因。

项目地点与售楼处是不同角色，不能共享同一语义字段；本轮不新增售楼处采集或单独图层。已有可靠范围可在选中时显示并注明来源，没有则只显示“暂无项目范围”。

### R4 价格口径隔离

二手房继续区分签约与挂牌。新房仅展示已有可信且明确口径的项目价格（如备案/参考均价），附来源与时间；没有则“暂无价格”，不从二手房快照推导或复用到新房字段。

新房点采用固定类别样式，不套二手房价格色阶；图例说明价格色阶仅适用于二手房。现有签约/挂牌切换仅影响二手房，不能让新房消失。新房不进入二手房均价、套数、市场行情等聚合指标。

### R5 就近比较

点开新房展示销售状态、价格口径、位置来源及配套，缺字段明确为空。提供“看附近二手房”，默认1.5公里直线范围，列出同一地图当前搜索/区域/物业条件下的二手房、距离、签约/挂牌价格及日期，可点击联动地图。进入此动作可切到全部，保留新房作为比较锚点，不清掉其他筛选；明确显示半径与限制条件，空结果不捏造数据。

这是一处就近浏览入口，不新增独立对比系统、不计算口径混杂的涨跌溢价。

## 验收标准

| ID | 需求 | 可验证结果 |
|---|---|---|
| A1 | R1 | 新房/二手/未知/售完固定样本分类正确；全部包含未知；三态切换数量、图层、详情一致，视角及其他筛选保留 |
| A2 | R2 | 新房无轮廓显示项目点和“新”标识，无问号方块、无建筑估算按钮；二手房行为不回归 |
| A3 | R3 | 合法项目点、待核验位置、无坐标、仅售楼处及冲突位置分别正确展示/隐藏并解释；没有虚构范围 |
| A4 | R4 | 新房有价/无价均不借用二手字段；签约/挂牌切换不隐藏新房；二手价格图例、指标和行情不受新房混入影响 |
| A5 | R5 | 附近1.5公里含边界点、域外点、无价点、筛选后空结果有测试；按距离稳定排序，点击列表联动正确对象，原新房锚点可辨认 |
| A6 | 全部 | 1440px桌面与375px窄屏无严重遮挡；缩放聚合/标签不堆叠，切换无残留标记，键盘能操作切换和列表 |
| A7 | 全部 | 后端相关及全量测试、前端lint/tsc/测试/build通过；隔离数据端到端覆盖切换→点项目→附近二手房→切回 |

## 范围外及默认决策

不新增顶层新房页、全量项目发现/抓价、规划图识别、自动轮廓生成、售楼处采集、多项目对比表、项目强制合并或收录规则迁移。不承诺已有数据覆盖所有新盘；不把规划配套当已建成设施。

全部默认、附近1.5公里、未知仅在全部出现是本规划默认值，供评审；用户已确认核心方向。无阻塞开任务的问题，实现需后续授权。
