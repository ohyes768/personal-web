# 宽基趋势观察改为完整周线拟合与周报

## Goal

将沪深300的历史回溯、当前通道和每周摘要统一为完整周线拟合，使通道版本随完整交易周更新，与周报节奏一致。

## Background

- 用户提出“改一下用周线呢？这样每周推送更靠谱一点的”，随后明确“trellis 规划任务完成就行”。本次交付仅为规划材料；任务保持 planning，不执行 task.py start。
- 目前后端使用月K拟合，日线定位，每周五19:00生成报告。近10年模型为120个完整月，成立以来从2005-04开始；历史固定窗口为10年训练、3年步进、最多3年观察。
- 2026-11-02只读核验：NAS前后端运行正常；现有快照收盘日为2026-10-30、3985.50点，拟合截至2026-09；最新周报记录为no_channel，钉钉未配置。换周线不能替代渠道配置，也不代表预测准确率提高。
- 腾讯周K接口可返回2005年以来的数据，实测末条为2026-11-02，属于未完成周，不能直接纳入拟合。

## Requirements

### R1 完整周数据

- 首版仍仅沪深300价格指数000300，保留原回归通道和宽度参数2，改用周收盘拟合。
- 自然周为周一至周日，时区Asia/Shanghai；周标识、该周实际最后交易日、抓取时间分别保存和展示。
- 未完成周可以展示，但不得参与拟合。交易周在交易日历确认的最后交易日15:05后完成；周五休市的短周同样适用。
- 用有覆盖范围的交易日历验证应有交易周和最新应有收盘。缺失行情、日历超范围、过期数据和整周休市必须区分；不能把“没有行情”当作“休市”。
- 整周休市不填造价格。回归和图形使用相同自然周时间坐标，不能因休市挤掉时间。

### R2 模型与历史

- 保留“近10年”“成立以来”两个当前模型，默认近10年。近10年为10个日历年的时间跨度，样本数按实际有交易周计，不使用120周或未经说明的固定520周替代。
- 新完整周生成不可变模型版本；同一周内仅更新最近完成交易日点位，不把进行中周的波动用于重拟合。
- 历史固定窗口保留10年训练、3年步进、最多3年观察的跨度，周归属规则必须明确，边界周不得混入观察期未来信息。
- 全历史与当前“成立以来”在同一截止周共用模型；后续观察数据不得参与固定窗口拟合。
- 通道位置仍不裁剪到0—100，区域阈值0/25/75/100保持不变；周线模型与月线模型不可混用。

### R3 页面和接口

- 两个Tab均显示周K；模型信息、日期、样本数量、拟合边界、延伸线和tooltip统一为周口径。
- 保留页面模型切换、历史窗口切换、URL恢复和缩放不重拟合；页面切换不改变周报持久化配置。
- 页面显示最近收盘日、模型截止周、最近应完成周和数据新鲜度，缓存过期仍可读但必须有明显标记。
- 保留约1年的趋势延伸，标明趋势参考而非目标价。

### R4 周报与迁移

- 每周五19:00先刷新、校验、发布本周快照，再生成周报。包含真实收盘日、点位、周涨跌、通道位置、区域、三轨、模型区间、样本周数和版本。
- 上周比较只使用同周期可比快照，区分价格变动与每周重拟合造成的位置变化；首次周线报告不直接与旧月线位置作同比较。
- 数据异常时发送异常说明；只有日历确认全周无交易才发送休市说明。未配置渠道继续保存no_channel，不能伪报送达。
- 保留现有每周发送去重键和旧周报原文、模型引用，不因切换周期重新投递已经发送的一周。
- 月线与周线数据、模型版本隔离；既有近10年月线周报配置迁移到近10年周线，成立以来配置迁移到成立以来周线，其他发送偏好保留。

## Acceptance Criteria

- [ ] AC1（R1）：盘中、周五15:05前后、短交易周、跨年ISO周均按交易日历正确判定，未完成周不进入拟合。
- [ ] AC2（R1）：整周休市保留时间槽但无虚构K线；缺失应有周/日、日历超范围和行情失败显示异常，不能生成正常摘要。
- [ ] AC3（R2）：近10年按日历区间选样；同周价格变化不改系数，新完整周生成新版本，旧模型保持不变。
- [ ] AC4（R2）：固定窗口使用声明的周边界和独立训练样本，修改观察期价格不改变系数；全历史和成立以来数值一致；区域边界回归通过。
- [ ] AC5（R3）：API、页面、tooltip和周报均为周字段及周单位；切换模型所有数值同步，375px/1440px可用，缩放不重拟合。
- [ ] AC6（R4）：周报模型与页面选择独立；涨跌和模型变化比较可复算；首次切换不将旧月线位置当作上周周线位置。
- [ ] AC7（R4）：旧库重复迁移安全，旧月线模型/报告仍可追溯；同周已sent不重发；no_channel、failed、重试和重启状态如实记录。
- [ ] AC8（R1—R4）：后端脱网测试、前端图表测试、类型检查和生产构建通过，真实行情只读联调有记录；部署与真实消息投递另行授权和验收。

- 实施范围不含增加指数、同时维护月线/周线切换、修改通道算法为标准RMSE、交易建议或预测准确率承诺。
