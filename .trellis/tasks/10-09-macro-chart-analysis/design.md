# 技术设计草案（planning，待范围与模型接入确认）

## 交互与范围
每个独立子图增加标题、指标说明及“帮我分析”入口。助手在页面级共享，图表通过稳定chart_id打开对应会话；不按数组位置/中文标题识别。会话头部展示所有主曲线和分析日期，可用快捷追问聚焦单曲线。图例隐藏不改变分析范围，首次分析前即可看见曲线列表。
首次分析使用可视x轴日期（缩放范围优先，否则Tab范围）；框外参考窗口若使用须单独标注。范围变化只标记过期，不自动调用。取消、请求序号与上下文标识共同防止晚到响应覆盖。切图隔离会话，保留页面内上下文；持久化待定。

## 架构
前端 ChartAnalysisContext → 分析HTTP接口 → 图表注册表 → 原始序列读取/质量检查/统计 → 不可变证据快照 → 单助手模型适配器 → 引用证据的回答。
公共提示词管理语言、事实/推断边界；每图配置管理分析规则。无需Skill或多Agent。模型厂商由独立适配层隔离，具体协议在选型后补齐。

ChartDefinition包含 chart_id、version、频率、主series_ids、依赖指标、可选关联指标、单位/展示变换、说明及分析策略。前后端共享可核验的描述契约，后端白名单为权威，不信任客户端提交数值、提示词和任意工具路径。
图表展示可以归一化，经济含义分析须同时拥有原始值及变换元数据；双轴不得按视觉高度比较绝对数值。

## API草案
- GET /api/analysis/charts：已支持图表及说明、曲线和能力。
- POST /api/analysis/sessions：chart_id、日期范围、view_mode、可选focus_series_id；自选图另带受限series_ids。后端返回session_id、snapshot_id、实际范围、曲线、质量和首次回答。
- POST /api/analysis/sessions/{id}/messages：message、request_id；始终引用原快照。
- 重分析建立新快照/会话，不覆盖旧回答。
返回结构含schema_version、prompt_version、definition_version、generated_at、每序列as_of、证据ID、回答及质量标记。错误区分参数非法、数据不足、未配置模型、服务不可用；取消和流式协议在实现设计细化时确定。
会话绑定访问主体，TTL和消息上限明确配置；多实例持久化不作为首期隐含能力。模型密钥仅在后端；超时、限流、输出长度及受限关联数据工具控制单次成本。沿用部署访问边界前须核对网关鉴权。

## 数据与计算
不直接把Plotly trace或前向填充后的展示数组当原始观测。通过DataService新增受控原始序列读取接口，返回观测日期/单位/来源/推导标记，避免分析服务直接散读CSV。
先检查可读性与新鲜度，再按同日数据计算起止差值、极值、有效样本数；空窗不视作0。利率差用百分点或bp（1个百分点=100bp）；百分比变化仅在指标适用且基数非零时使用。
中国源当前只有10y和10y−2y：2y=10y−利差，只在共同有效日期推导并注明来源；分解Δ利差=Δ10y−Δ2y。若将来引入独立2y，校验口径再替换。
参考DR007与主图数据分开说明；数据不足时缩小结论，不补造因果。工具只能读取白名单序列，限制轮数与区间。快照生成需考虑CSV读写竞争，无法取得一致数据时返回可重试错误，不把读取异常当正常空值。

## 接入清单
| 图表组件 | 需要覆盖的日频子图 | 特别事项 |
|---|---|---|
| RatesChart | 短端利率、TED、中国国债 | 首期中国国债；同单位不代表同一市场 |
| EconomicChart | 美债、汇率 | 汇率显示相对变化，保留基期及原值 |
| LiquidityChart | VIX、HIBOR、TGA | TGA单位换算 |
| MarketSentimentChart | 成交额、融资余额、换手率组合 | 双轴与不同指标含义 |
| HsgtFundFlowChart | 北向成交额、南向净流入 | 成交额不等于净流入 |
| CommodityChart | 金银、原油铜 | 多单位、多来源 |
| StockIndexChart | 恒生上证、标普纳指、道指 | 交易日和时区不一致 |
| ComparisonChart | 所有日频自选组合 | 动态指标、归一化、百分位、相关性；不得因相关推断因果 |

月频欧日债/混合频率图需能力声明，不能冒充日频；实际逐图清单在扩展阶段逐一验收。
