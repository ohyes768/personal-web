# 技术设计草案（planning，产品范围与模型提供方已确认）

## 交互与范围
每个独立子图增加标题、指标说明及“帮我分析”入口。助手在页面级共享，图表通过稳定chart_id打开对应会话；不按数组位置/中文标题识别。会话头部展示所有主曲线和分析日期，可用快捷追问聚焦单曲线。图例隐藏不改变分析范围，首次分析前即可看见曲线列表。
首次分析使用可视x轴日期（缩放范围优先，否则Tab范围）；框外参考窗口若使用须单独标注。范围变化只标记过期，不自动调用。取消、请求序号与上下文标识共同防止晚到响应覆盖。切图隔离会话，保留页面内上下文；用户已确认刷新后清空，不跨刷新恢复。

## 架构
前端 ChartAnalysisContext → 分析HTTP接口 → 图表注册表 → 原始序列读取/质量检查/统计 → 不可变证据快照 → 单助手模型适配器 → 引用证据的回答。
公共提示词管理语言、事实/推断边界；每图配置管理分析规则。无需Skill或多Agent。模型厂商由独立适配层隔离，具体协议在选型后补齐。

ChartDefinition包含 chart_id、version、频率、主series_ids、依赖指标、可选关联指标、单位/展示变换、说明及分析策略。前后端共享可核验的描述契约，后端白名单为权威，不信任客户端提交数值、提示词和任意工具路径。
图表展示可以归一化，经济含义分析须同时拥有原始值及变换元数据；双轴不得按视觉高度比较绝对数值。

## API草案
- GET /api/analysis/charts：已支持图表及说明、曲线和能力。
- POST /api/analysis/sessions：chart_id、日期范围、view_mode、可选focus_series_id；自选图另带受限series_ids。后端返回session_id、snapshot_id、实际范围、曲线、质量和首次回答。
- POST /api/analysis/sessions/{id}/messages：message、request_id；始终引用原快照。
- 重分析建立新快照/会话，不覆盖旧回答。
返回结构含schema_version、prompt_version、definition_version、generated_at、每序列as_of、证据ID、回答及质量标记。错误区分参数非法、数据不足、未配置模型、服务不可用；取消和流式协议在实现设计细化时确定。
会话绑定访问主体，TTL和消息上限明确配置；多实例持久化不作为首期隐含能力。模型密钥仅在后端；超时、限流、输出长度及受限关联数据工具控制单次成本。沿用部署访问边界前须核对网关鉴权。

## 数据与计算
不直接把ECharts展示序列或前向填充后的展示数组当原始观测。通过DataService新增受控原始序列读取接口，返回观测日期/单位/来源/推导标记，避免分析服务直接散读CSV。
先检查可读性与新鲜度，再按同日数据计算起止差值、极值、有效样本数；空窗不视作0。利率差用百分点或bp（1个百分点=100bp）；百分比变化仅在指标适用且基数非零时使用。
中国源当前只有10y和10y−2y：2y=10y−利差，只在共同有效日期推导并注明来源；分解Δ利差=Δ10y−Δ2y。若将来引入独立2y，校验口径再替换。
参考DR007与主图数据分开说明；数据不足时缩小结论，不补造因果。工具只能读取白名单序列，限制轮数与区间。快照生成需考虑CSV读写竞争，无法取得一致数据时返回可重试错误，不把读取异常当正常空值。

## 兼容、风险与回滚
ECharts接入前置已落地（按用户完成声明及代码核对，未重跑其验收）；复用MacroEChart/LinkedSubplots现有上下文回调接入助手UI；遵守macro-echarts约定，通过ChartContext/onContextChange读取稳定图表标识、完整曲线集合、展示变换与日期范围，不访问ECharts实例内部对象。模型未配置时入口可解释不可用，原图仍可正常使用。功能开关关闭分析即可回滚；不改变采集调度或原CSV格式。


## 2026-10-10 接入细化
- rates.china-bonds直接映射后端图定义，主指标cn_10y、cn_10y_2y；cn_2y是计算依赖，dr007是参考指标。
- 页面协调器维护Map<chartId, ChartContext>，不得只保存最后一个回调。联动缩放会让多子图回调，只有用户点击分析的图决定助手上下文。
- 在Tab透传onContextChange并增加图表操作入口；公共图表外壳通过onAnalyze(chartId)打开共享助手。渲染器只提供上下文，保持不调用模型。
- ChartContext目前无频率、来源时间、数据版本、归一化基期或相关性窗口/指标对。这些由业务层分析上下文补充并在后端校验；不把显示单位作为原始单位。
- 渲染器会剔除空曲线；配置注册表保留预期指标，缺失显式标记，不随渲染结果删除。动态对比图另传受限指标集与模式参数，不依赖解析拼接chartId来建立完整语义。
- 同一日期范围的数据刷新仍可能改变数值；补充业务数据revision或快照指纹，不仅按chartId+dateRange判定回答是否过期。
- 模型协议、首期是否流式输出、会话TTL和访问控制仍需细化（历史范围已确定为本次页面会话）；选择服务提供方后再确定实现依赖与部署配置。

## 页面会话决定（2026-10-10）
用户确认首期刷新页面后清空聊天。前端会话ID与聊天记录仅保存在React页面状态，不写localStorage或跨刷新恢复。切图时按chartId保存本页会话。后端保留临时快照/会话以支持追问，并通过TTL及容量上限清理；前端刷新意味着不再恢复旧会话，不等于后端立即物理删除。服务重启或TTL过期时显示“会话已过期，请重新分析”，具体TTL在实施前细化。不增加聊天数据库。

## 分析范围决定（2026-10-10）
用户确认“帮我分析”默认分析当前单个子图的全部主曲线，追问可以聚焦其中一条。图例隐藏不改变成员；相邻子图不自动纳入，关联参考数据单独标注。该行为作为所有日频图的通用交互契约。


## 实施基线 v1（2026-10-10；默认工程选项，访问方式待确认）
### DeepSeek与响应
复用httpx.AsyncClient调用标准chat/completions，不新增Agent框架。默认建议deepseek-flash并显式关闭thinking，名称可由DEEPSEEK_MODEL覆盖；模型标识依据research官方核对，实施前复核。DEEPSEEK_API_KEY通过部署环境注入，DEEPSEEK_BASE_URL默认https://api.deepseek.com，仅运维配置，客户端不可指定。
使用流式Markdown正文，不要求模型生成整份API JSON；数值证据、质量、会话等元数据由代码生成。只展示content，不展示reasoning_content。默认输出上限2048 tokens、连接10秒、整轮90秒（可配置）。超时后不自动重试付费生成；提供手动重试，重复request_id返回已有状态而非再次调用。

### HTTP协议收敛（替代早期“建会话即返回首次回答”草图）
1. GET /api/analysis/charts返回后端支持清单/说明。
2. POST /api/analysis/sessions只创建证据快照和会话，不调用模型；返回session_id、snapshot_id、上下文、质量与expiry。前端打开助手后创建，然后发送首轮生成请求。
3. POST /api/analysis/sessions/{id}/messages通过fetch读取SSE（不用原生EventSource），body含request_id和message；首次为固定“请分析当前图”。事件为meta/delta/done/error，done带message_id和usage。建立流前错误使用HTTP错误，流建立后使用error事件；没有done的回答为未完成，不能进入完整历史。
4. DELETE /api/analysis/sessions/{id}/requests/{request_id}显式取消并终止本地上游任务；同时处理客户端断开。取消不承诺撤销已经产生的模型费用。
5. GET /api/analysis/sessions/{id}/requests/{request_id}查看完成/失败/取消状态，断线后取最终结果而非重复生成。单会话仅一个生成任务，重复ID不并发生成。
不修改既有业务响应包裹约定；流式接口独立声明。HTTP 400/422参数错误，401/403访问问题，404未知，410过期，409生成中，429限流，503未配置/上游不可用。请求级ID与会话所有者均校验。

### 会话与成本默认值
单worker内存会话，闲置30分钟过期、最长2小时、最多100个会话，过期会话定期清理；不会淘汰仍运行的请求，容量满拒绝新建。每会话最多10轮、用户单条2000字符，完整历史加快照须受输入预算约束，超限提示新建分析，不静默删掉证据。全局最多2个生成请求，访问主体每分钟5次；没有可信主体前不宣称主体隔离已实现。
第一版在建快照时固定加载主数据、衍生数据与DR007参考，不启用任意模型工具循环。追问请求其他范围/未准备指标时明确让用户切图或重分析。后续通过受限工具扩展，保持初次快照和新增证据时间边界明确。

### 快照、显示与网关
快照包括实际共同观测日期、起止值/差值/极值、最近有效数据日期、完整预期指标列表、缺失状态和来源；数据摘要必须覆盖完整分析范围，若展示采样需披露采样，统计仍基于完整观测。短样本只描述数据不做趋势结论。
前端分析上下文按图ID保存，包含业务revision、显示模式/基期等；后端快照指纹包含原始内容和图定义版本，不依赖客户端指纹作为权威。初次输出约300至600中文字，追问按问题控制篇幅，长内容可折叠。
流式路径增加专用nginx代理配置proxy_buffering off、禁用该路径缓存、适当proxy_read_timeout；优先级和rewrite与现有/api/macro保持一致。使用心跳避免空闲断开。Markdown复用安全渲染，不允许原始HTML。访问方式未确认前模型功能默认关闭，不把服务密钥用于浏览器鉴权。
