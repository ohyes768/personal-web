# 执行计划草案

本任务当前仅规划。完成范围/模型接入决策与文档审阅后才执行 task.py start。

1. 等待ECharts重构完成并验收，复用ChartContext/onContextChange；核对全部日频图表、原始数据列与单位，补全research清单；确认模型服务、访问控制及会话保存范围。
2. 定义ChartDefinition、分析请求/响应、快照/证据契约；以中国国债和一个多曲线双轴图验证结构。
3. 实现原始数据读取与统计：共同日期、缺失质量、推导2y、bp/百分点、展示变换；用固定夹具测试。
4. 实现模型适配器、公共提示词与图配置、受限参考数据工具、会话TTL/超时/限流及错误映射。模型调用用fake适配器进行确定性契约测试，真实模型另做人工质量验收。
5. 接入共享助手UI和子图外壳：说明、范围/曲线预览、初次分析、追问、取消重试、上下文变更提醒。首先开放中国国债。
6. 验证第二类图表只需配置/数据映射即可接入，不复制助手；评审后按design清单分批扩展所有日频图。
7. 检查前后端契约、部署配置、数据日期展示及提示词版本；完善spec并按Trellis流程提交/收尾。

## 验证
- 后端：pytest 新增图表注册、快照统计、分析接口与会话隔离测试；运行受影响已有查询/快照测试。实际命令使用backend testing-environment指定环境。
- 前端：pnpm --dir apps/macro exec tsc --noEmit；pnpm --dir apps/macro build（先确认无同目录dev实例）。
- 浏览器：真实缩放、拖拽、双击复位、图例切换、快速切图/区间、旧响应晚返回、重复点击、取消、数据不足、移动端。
- 输出验收：所有数值可追溯证据，衍生2y有标签，无数据时不虚构，双轴/归一化不误读。
