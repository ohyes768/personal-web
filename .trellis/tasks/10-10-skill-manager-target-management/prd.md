# Skill 导出目标管理

## 目标
用户能在技能管理器界面管理外部导出目标，不再依赖修改代码新增目标。

## 已确认背景
- 当前导出目标固定为 windows-codex / windows-claude，定义在前端 targets.ts 和后端 models.py。
- 导出为 ZIP 下载，SQLite 保存每个技能和目标的版本台账；管理台不能确认本机是否安装。
- OpenClaw / Hermes 使用 NAS symlink 发布，依赖固定目录配置，与 ZIP 导出不同。
- 用户已要求规划并实施本功能；创建独立任务，不修改其他现有任务。

## 需求
1. 新增“导出目标”管理入口，支持新增、编辑名称、安装目录说明、备注、启用/停用及删除。
2. 可为不同工具或设备创建独立目标；目标 ID 创建后不变，名称可编辑。
3. 两个现有 Windows 目标自动迁移为初始数据，保留历史导出记录。
4. 导出弹窗动态列出启用目标，展示安装目录说明；目标配置持久化到 SQLite。
5. 停用目标不能新导出，历史记录仍可查询、清除；有记录的目标需先清除记录才能删除。
6. OpenClaw / Hermes 保持现有发布配置。

## 验收
- 新建目标后无需修改代码或重启，即可选中并下载 ZIP，产生对应记录。
- 改名、刷新页面或重启后配置与记录保留；改名不拆分历史台账。
- 旧 Windows 台账仍可查看、重新导出、清除。
- 停用、空目标列表、重复 ID、已有记录删除等场景有明确提示。
- 自定义导出目标不进入发布队列、symlink 核对或启动重发布。

## 已确认范围
用户选择只管理 ZIP 导出目标并要求开始实施。

## 范围外
自动写入 Windows 目录、远程安装、SSH 传输、批量导出、改造 NAS 挂载配置。
