# 扫描缓存复用

用户已直接授权实施：扫描结果留作缓存，登记只做目录检查和入库。

## 方案
缺少缓存时以 --depth 1 下载到共享缓存根的 .tmp，扫描并校验 HEAD/SKILL.md 后原子移入 repos。已有有效缓存继续离线扫描；单项与批量登记复用现有离线分支。失败、空候选不留下正式缓存；并发时复用有效先落地的仓库，禁止覆盖无效的既有目录。

## 验收
- 首次扫描保留正式缓存；二次扫描、单项及批量登记不再 clone/fetch/ls-remote。
- 失败和空候选清理临时目录；启动清理不删除正式缓存。
- 并发落地不覆盖先完成的缓存，返回实际缓存中的候选。
- Git 流式进度、浅克隆、登记版本记录、发布 staging 与密码边界保持。
- Windows 本地 Git fixture 验证缓存/任务/API，不使用 WSL、NAS 或真实 GitHub 下载。

## 步骤
先写缓存保留与登记零网络测试并看到失败；修改 scan；更新旧临时扫描测试和文案/规范；运行后端相关及完整回归。用户未要求提交/推送/部署，本轮不执行。
