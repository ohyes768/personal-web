# 收藏跟踪估值列重构与估值阅读页

## Goal

重构股息率收藏跟踪表的评估相关列（评估/版本、评估状态、操作），补齐评估/再评估入口与状态可见性，会话下载归位到评估溯源，并新增独立估值报告阅读页 /valuation-reader（对齐 /quality-reader）。

## Requirements

### R1 评估入口常驻

- 每一行都必须有评估入口，不因「已评估」而消失。
- 文案随状态区分：从未评估 →「评估挡位」；最近一次失败 →「重试评估」；已有成功报告 →「再评估」。
- 「待应用」行同样要保留再评估入口（当前缺失）。
- 再评估覆盖待应用报告时，**弹确认**：「重新评估会覆盖当前待应用的报告（尚未生效），已生效挡位不受影响。确认重新评估？」取消则不提交。

### R2 状态可见

- 行内状态徽章覆盖：待评估 / 评估中 / 评估失败 / 已取消 / 未出价格 / 评估完成 / 待应用。
- 评估中显示队列位次，让用户不打开队列面板也知道排第几。
- 失败行显示失败原因原文。
- 失败不得掩盖「待应用」：最近一次尝试失败但仍有一份待应用的报告时，两个状态都要露出，且仍可应用或重试。

### R3 会话下载归位

- 成功与失败的最近一次尝试都要能下载该次 Hermes 会话记录。
- 下载入口与「这次尝试的时间 + 版本」放在同一列，四者必须指向同一次尝试，不得出现「下载失败那次、时间写上次成功那次」的错位。
- 被取消的尝试同样可下载。

### R4 报告阅读页

- 新增独立路由 `/valuation-reader`，视觉与交互对齐已有的 `/quality-reader`。
- URL 用 `code` 标识当前股票，支持下拉切换、上一篇/下一篇、刷新、返回主页面并还原视图。
- 阅读集合为「有估值报告的股票」，按代码升序；**失败股票不进集合**（没有报告可读，失败信息与失败会话下载留在收藏跟踪表）。
- 估值报告**只有阅读页一个入口**，弹窗版删除，避免两套渲染走偏。行内「应用」仍走紧凑确认卡。
- 阅读页提供：报告全文、应用挡位、再评估、下载会话记录。

### R5 列职责收敛

- 收藏跟踪表从 7 列收敛为 6 列：股票/基本面 │ 现价 │ 挡位 │ 区间 │ 评估 │ 操作。
- 「评估」列承载：attempt 状态徽章 + attempt 时间/版本 + 会话下载。
- 「挡位」列承载：**只画一条**（生效挡位条；无生效挡位时画候选条）。有待应用候选时加一行脚注 `生效于 {应用时间} · 新挡位待应用`。**不叠第二条条**——候选那套价由「应用」确认卡与阅读页承载。
- 生效挡位**不标版本号**：报告按 code 覆盖写，新报告成功后旧报告即被顶掉，生效挡位当年用的哪版 skill 事后查不到；可靠可查的只有应用时刻。
- 「操作」列承载：单行按钮组，不再两层堆叠。
- 「需重评」提示统一口径：基本面列也必须与已部署版本比较后再提示。

### R6 口径一致

- 版本与时间必须贴着它描述的那套挡位，不再出现「条是生效的、时间是最新报告的」错位。
- 手工挡位行的徽章不再显示「待评估」，改为「手工挡位」。

## Constraints

- 不改后端接口契约；`per_code` 已带 `finished_at`/`updated_at`/`run_id`，够渲染 attempt 溯源。
- 不改 nginx 配置：`location /dividend/` 已能代理新路由。
- 报告 Markdown 渲染复用 `md-body` / `quality-reader-md` 样式，不新增第二套样式。
- 阅读页用普通 `<a>` 整页导航，不用 Next 客户端路由（线上 nginx 剥前缀）。
- 区间判定口径不变，继续与后端 `AlertService` 一致。

## Acceptance Criteria

- [ ] 已评估且已应用的行，「操作」列出现「再评估」按钮
- [ ] 待应用的行同时出现「应用」「查看报告」「再评估」
- [ ] 最近一次尝试失败、但仍存在待应用报告的行，徽章显示失败原因，且「应用」与「重试评估」同时可见
- [ ] 评估列第二行的时间、版本、下载按钮指向同一次尝试
- [ ] 存在生效挡位且有待应用报告时，挡位列**只画一条条**，脚注写明生效时间并标出「新挡位待应用」；候选的四条价不出现在表格里
- [ ] 基本面评分版本与已部署版本不一致时，行内出现「需重评」
- [ ] 纯手工挡位行徽章为「手工挡位」，不再显示「待评估」
- [ ] `/valuation-reader?code=<code>` 可直接打开并显示对应报告
- [ ] 阅读页下拉切换、上一篇/下一篇可用，返回链接回到进入前的视图
- [ ] 阅读页可应用挡位、可再评估、可下载会话记录
- [ ] 现有 e2e 全部通过；列名断言与新增用例同步更新
