# 夏普走势页：单基金滚动夏普稳定性视图

## Goal

新增导航第七 Tab「夏普走势」（`/funds/sharpe-trend?code=xxx`），用**现算的周频滚动 3 年夏普曲线**回答「这只基金稳不稳」。

现有三个视角各自回答不同问题，本任务是补上缺的那个：

| 页面 | 回答 | 数据 |
|---|---|---|
| 股基两 tab 列表 | 现在谁好？ | 每周刷新的一帧快照 |
| 夏普榜单 | 谁一直好？（横向比 N 只） | 每周冻结的周观测，**只在 ≥0.8 时记录** |
| **夏普走势（本任务）** | **这一只稳不稳？（纵向看单只）** | 现算完整曲线，**跌破 0.8 也看得见** |

关键动机：夏普榜单的观测有幸存者偏差——基金跌破 0.8 就落榜、曲线断线，而「下坠过程」恰恰是判断稳定性最该看的段落。走势页不受此限。

## Requirements

### R1 后端：现算滚动夏普

- 新增 `GET /api/funds/sharpe-trend/{code}`，参数 `range=all|3y|1y`（默认 all）。
- 滚动窗口固定**穿透 3 年**（`WINDOW_YEARS=3`），每个**自然周最后一个交易日**出一期，从「首个满足最小样本的周」到「最新净值日所在周」。
- **必须用纯净值口径**：`r_p`（东财日增长率/100）+ `r_f`，**不 join `fund_benchmark`**。
  依据（已实测 000628）：基准数据只从 2023-11-08 起，inner join 会把历史窗口的 3 年样本截断到 1 年，夏普从 0.68 跳到 2.42（2024-09-30 窗口：join 版 2.42/n=219，纯净值版 0.68/n=729）。夏普定义只需基金收益与无风险利率，基准只服务 IR/alpha。
- 最小样本 `MIN_SAMPLE_DAYS=250`，不足该周不出点（曲线起点自然后移约 1 年）。
- 与 `risk_service` 同口径：`mean/std(ddof=1) × √252`；`std=0` 或 NaN → 无定义（不出点）。
- `risk_free_rate` 可用则按年化小数/252 折日频并对齐 ffill；**生产库该表当前为空**——缺失时按 rf=0 计算，并在响应中如实标注 `rf_basis`，不得静默。

### R2 后端：稳定性 KPI

- `current`：最新周点夏普（必然等于列表夏普列的纯净值口径值）。
- `max` / `min` / `mean`：展示区间内有效点的最高/最低/均值。
- `above_ratio`：达标周数 / 有效周数（达标 = ≥ `threshold`）。
- `consecutive_above`：从最新周点往回数，连续 ≥ 阈值 的周数。
- `longest_below`：全区间**最长连续 < 阈值**的周数（回答「最差能差多久」）。
- `trend_12w`：最近 12 个点的线性斜率（每周变化量）；点不足 12 个返回 null。
- `threshold` 默认 **0.8**（与夏普榜单入选线一致）。

### R3 后端：性能与缓存

- 实测：单只净值拉取 0.12s，603 个周点计算 0.17s → 单请求 < 0.5s，无需预计算落库。
- 净值外部请求加**进程内 TTL 缓存**（默认 1 小时，按 code 键），避免区间切换重复打网络；缓存不做持久化，重启失效可接受。
- 净值拉取失败 → 502 或结构化错误（区分「网络失败」与「确实无历史」），不得返回空曲线冒充正常。

### R4 前端：第七 Tab

- `FundsNavigation` 增加 `sharpe-trend` 项（排夏普榜单之后），`FundsNavTab` 类型同步。
- 页面自行组装头部（同 sharpe-board 模式，不套 FundsHeader）+ `FundsNavigation active="sharpe-trend"`。
- **无 code 时**：显示代码输入框 + 引导文案（不在无选中时造一条曲线）。
- **带 code 时**：自动加载并渲染。
- 图表复用 `SharpeChart` + `buildSharpeChartOption`（单 series，`minLatestSharpe=0.8` 挂参考线）；`dynamic(ssr:false)`。
- 区间切换 `all/3y/1y` 走 query，切区间不整页刷新。

### R5 三处入口（全部带 code 跳转）

1. **股基两 tab 列表的代码列** → 可点跳走势页。`FundTable` 加 `trendEnabled` prop，**只有 `stock` / `discovery-stock` 传 true**；债基两 tab UI 行为不变（不出现死链）。
2. **详情抽屉夏普 KPI** → 可点跳走势页。抽屉是浮层，用 `Link` 跳转并关闭抽屉。
3. **夏普榜单行的基金代码** → 可点跳走势页。

basePath 铁律：所有跳转 `Link` 用相对路径（`/sharpe-trend?code=...`），**不得**带 `/funds` 前缀（否则变 `/funds/funds/...` 404）。

## Acceptance Criteria

- [ ] `GET /api/funds/sharpe-trend/000628` 返回完整 points，最新点夏普与 `fund_risk_metrics.sharpe` 纯净值口径一致（差异仅来自「最新周点 vs 最新交易日」的对齐，需在文档中写明）。
- [ ] 有基准数据的基金（如 000628）历史窗口**不因 benchmark 缺失而被截断**：2024-09-30 窗口的 sample_days ≈ 729 而非 219。
- [ ] `risk_free_rate` 为空时响应 `rf_basis="zero"` 且曲线正常产出（不得 500）。
- [ ] 净值不足 250 日的基金 → `points=[]` + 明确的 insufficient 诊断，前端显示「历史不足，无法计算」而非空白图。
- [ ] 代码不存在 / 净值网络失败 → 结构化错误，前端可重试。
- [ ] KPI 六项数值有单测覆盖（含边界：全达标、全不达标、恰好 12 点、单点）。
- [ ] 第七 Tab 出现在导航，`/funds/sharpe-trend` 无 code 可正常落地不报错。
- [ ] 三处入口可用：股基两 tab 代码列点击进走势页；债基两 tab 代码列**不可点**；抽屉夏普 KPI 可点；夏普榜单行代码可点。
- [ ] 375px / 1440px 布局不溢出；图表容器有高度（Tailwind 任意值类陈旧缓存坑须知）。
- [ ] 后端全量测试通过（当前基线 597 passed）；前端 `tsc --noEmit` 通过。

## Constraints

- **不改任何采集链路**：走势页纯读、纯现算，不写库、不进调度、不影响周榜发布。`sharpe_board_*` 表零写入。
- 第一版**只支持股基**（债基入口不开）。后端对任意 code 都能算，但前端不暴露债基入口。
- 不引入新的持久化表（性能已验证不需要）。
- 新增静态路由 `sharpe-trend` 必须注册在通用 `/{code}` 之前（`main.py` 顺序铁律）。

## Notes

- 与「夏普榜单」的关系：榜单看**在榜资历**（横向、有幸存者偏差），走势看**完整曲线**（纵向、无偏差）。二者最新值同口径，可互相印证。
- 后续可选：走势图叠加「在榜区间」背景带（把榜单周观测当辅助层）；本任务不做。
