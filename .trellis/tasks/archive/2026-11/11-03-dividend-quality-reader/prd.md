# 基本面资料手机阅读界面

## 目标与用户价值

手机上以独立、连续的阅读体验查看已经生成的公司基本面报告，不必在宽表格和弹窗之间反复切换。股息率页面提供「基本面资料阅读」入口，阅读时可翻上一篇/下一篇，也可下拉直接选择股票。

## 授权与当前阶段

- 用户原始需求：「现在基本面评分有结果了」「手机上看，单独做个阅读界面」「上一个/下一个（或者下拉具体选哪个）」「基本面资料阅读入口」。
- 2026-11-03 用户追加：「建任务吧，规划都做好」。本轮交付完整规划；任务维持 planning，后续收到实现指令再启动。
- 下文是据原始需求收敛的首版方案；默认规则已明确，不存在阻塞规划的产品问题。用户仍可在实现前调整。

## 已确认的现状

- 结果包含五维评分、摘要、风险、关注点、完整 Markdown、数据日期、评分时间、Skill 版本和耗时，类型见 `apps/dividend/src/lib/quality.ts:18`。
- 已有全量结果读取方法 `apps/dividend/src/lib/api.ts:44`，报告位于选股关注表格的弹窗，正文见 `apps/dividend/src/components/QualityReportModal.tsx:41`。
- 项目已有暖白底与墨色文字、Markdown 排版和版本提示组件，详见 `research/codebase.md`。
- 当前部署为无 basePath 的 Next 应用经 `/dividend/` 路径反代，需覆盖线上路径访问验收。

## 需求

| ID | 需求 |
| --- | --- |
| R1 | 股息率主页面在手机可见的位置增加「基本面资料阅读」入口，全部股票、预警、选股关注视图均能进入；保留现有评分弹窗。主表加载不应阻塞阅读入口。 |
| R2 | 独立阅读页一次展示一家公司：名称、代码、日期、耗时、版本提示、摘要、五维评分、风险、关注点、完整报告。缺失维度显示「未评分」，不合成总分或星级。历史正文原样保留。 |
| R3 | 阅读集合覆盖全部已保存的评分结果，包括存在 null 维度的报告；不受主页面股息率阈值、筛选结果、收藏状态约束。按六位股票代码升序，首篇默认最小代码，翻页顺序稳定。 |
| R4 | 同时提供下拉选择与底部上一篇/下一篇；下拉项为「代码 名称」，展示「第 X / N 篇」。首末篇禁用对应按钮，不循环；只有一篇时两按钮均禁用。 |
| R5 | 阅读链接标识当前股票，复制、收藏网址、刷新、浏览器前进后退均能还原当前公司。主动切换公司回到正文顶部；无需逐篇保存历史滚动位置。 |
| R6 | 手机采用单栏：正文默认 17px、行高 1.8、左右至少 16px 留白，控件触摸区域至少 44px；底部翻页适配安全区并给正文留足空间。正文、长链接不会造成整页横向滚动，宽表格和代码块局部横滑。桌面限制正文宽度，保持可读行长。 |
| R7 | 明确区分加载、请求失败、无结果、指定报告不存在和正文缺失；失败可重试。已有内容刷新失败保留旧内容并提示。提供手动「刷新资料」，不会自动换篇或打断阅读。 |
| R8 | 阅读页提供「返回股息率」链接。站内入口返回原视图（仅保留 tab/fav 等有效参数）；直接打开阅读链接时返回股息率默认页。本地直连与线上 `/dividend/` 均可访问、刷新、返回。 |

| AC8 | 全部 | 类型检查、生产构建、阅读页浏览器测试及现有 screening 回归通过；桌面/手机截图人工检查通过，结果记录到任务验证文档。 |
