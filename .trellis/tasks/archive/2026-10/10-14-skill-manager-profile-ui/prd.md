## 需求

### R1 界面入口和默认目录

新增与“导出目标”并列的“安装目标”入口。显示默认目录和各 profile 的名称、实际 skills 路径、可用状态、已安装数量、不可用原因。默认 `hermes` 行为固定只读，不能从网页改目录或删除，原 ID、目录、链接和历史保持不变。管理/安装看板的选择器提供直达管理入口。

### R2 新增与编辑

新增时选择已存在的 profile；路径只由服务端定位为已挂载父目录下该 profile 的 `skills` 子目录，不填写任意绝对路径。显示完整写入目录，填写显示名称，管理密码确认后保存。只有目录存在、可访问且符合授权边界的目标可新增；不创建 Hermes profile 或其缺失 skills 目录。不自动安装任何 Skill。

已登记目标可以修改显示名称；profile 身份、ID 和目录不可换，避免把同一目标移往另一环境。新保存的目标立即出现在管理/部署选择器和安装多选弹窗，刷新或重启后保留。删除后重新登记同一 profile 恢复原身份，不复用它给其他目录。

### R3 删除和历史保护

以 active 安装台账作为删除阻止依据；缺失链接、不可访问目标、离线目录也不能推断已下架。明确展示阻止删除的 Skill 数量，提供进入该目标部署看板的入口，先由用户正常下架。没有 active 安装后才可密码确认删除目标配置；不删除磁盘目录、外部文件、源 Skill 或审计历史。旧历史保留为已移除目标，不出现在可安装清单。默认目标始终不可删。

### R4 目录与操作边界

部署授权固定默认根与 profiles 父根，网页不能改授权根或访问其他服务器路径。识别 profiles 直接子目录，只接受其实际 skills 子目录；逃逸路径、符号链接重定向、与源库/缓存/state 重叠或其他目标规范根重复均拒绝。目录缺失/无权限清楚提示，名单加载失败不静默切目标。父挂载包含其他文件，但管理 API 不读写 profile 配置和凭据。

### R5 持久配置与兼容

默认根仍由部署配置保持安装身份；profile 目标采用 SQLite 持久配置作为管理真源。首次升级只从当时受信任的 env 目标配置导入一次，不把仅有历史的 catalog 行变成可写授权；后续启动不再覆盖网页改名或复活已删除目标。无法映射到授权 profiles 根的旧 named 目标保留台账和异常说明，不自动转移链接或删数据。

目标新增/改名/删除均密码校验并审计，错误密码或无效参数无副作用。更新与安装执行串行并事务复验，旧目标配置指纹变化使预览失效。并发删除和安装不能产生被删除目标的新 active 台账。目标不可用不影响其他目标或 ZIP 导出；任一有效/异常 active 安装继续阻止源误删。

## 验收

- AC1/R1：默认行只读；安装目标与 ZIP 导出管理清楚分开，选择器能跳到目标管理。
- AC2/R2：一次部署后网页新增两个后续 profile，全程无需 `.env`、额外挂载或重启；保存立即可选，重启后保留。
- AC3/R2/R4：源为服务发现的现有 profile/skills；未知/缺失/无权限/逃逸/重复根清楚报错，无目录创建、链接或凭据操作。
- AC4/R2/R5：改名不改目标身份和链接；重复新增拒绝，删除后重新添加沿用身份，原 env 不覆盖网页修改。
- AC5/R3：有 active 安装时删除返回冲突且给出数量/Skill；异常或不可达台账同样阻止。全下架后只移除目标配置，目录和历史保留，默认目标删除被拒绝。
- AC6/R5：旧 default/named 正常配置一次性导入，历史 catalog 不获授权；已有多目标安装、卸载、共享 HEAD 和失败精确重试不回退。
- AC7/R4/R5：错误密码、过期目标版本、计划后改名/删除、并发安装/删除可验证且不留下孤立安装记录；ZIP、仅登记和合集下载回归。
- AC8：后端全量测试、前端测试/类型/lint/build与浏览器模拟验收通过；真实 NAS/Hermes 验收单独记录，不以模拟结果代替。
