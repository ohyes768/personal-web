# 住宅目录高德分类复核与冲突审核

## 背景
透明售房网（TMSF）的用途标签是现行 `tmsf-directory-v1` 目录收录的唯一判决依据：标「商贸」等非住宅类型直接不收录，且目录模式下禁止人工 admit，没有任何纠错出口。2026-10-23 实锤案例：风雅钱塘世纪花园（TMSF 10001039）被 TMSF 标「商贸」而不收录，但克而瑞（住宅）、房天下（普通住宅）、高德（住宅小区 120302）三方一致表明其为住宅小区，且因此无法进入租金采集。用户已确认方案（见 research/findings.md）：透明售房网采集 → 高德匹配并复核分类 → 分流已收录/未收录/待审核。

## 目标
给住宅目录用途分类加「高德第二来源复核 + 冲突人工审核」：TMSF 错标不再一票否决；分类冲突进入待审核由人带证据确认；确认结果独立保存，刷新与再采集不覆盖；高德证据永不自动收录或排除。

## 决策矩阵（用户已确认，为本任务的需求定义）
| TMSF 分类 | 高德分类 | 处理结果 |
|---|---|---|
| 住宅 | 住宅小区 | 已收录（维持现判定，复核一致） |
| 明确非住宅 | 明确非住宅 | 未收录，保留原因（维持现判定，复核一致） |
| 住宅 | 明确非住宅 | 待审核：分类冲突 |
| 明确非住宅 | 住宅小区 | 待审核：分类冲突 |
| 任一方分类不明、商住混合 | 任意 | 待审核：用途待确认 |
| 高德未找到、匹配不确定 | 任意 | 待复核：不改变 TMSF 现判定，可重试 |

补充规则：
- 查询失败/未找到 ≠ 复核不通过；不得据此判非住宅。
- 分类复核只是收录条件之一，区域/地址/挂牌数量等既有门槛不变。
- 人工审核结果权威且独立保存；出现新的相反证据时回到待审核并提示复审。
- 高德「明确非住宅」的判定必须来自同区、名称匹配（复用现有拉平/别名规则）的 POI，匹配不确定一律按「待复核」处理。

## 要求
- R1 复核证据采集：对目录内小区做低频、有界、可取消的不限类型高德 POI 搜索；按身份指纹缓存与失效；复用现有名称拉平/别名/区域/边界匹配规则；记录 POI id、typecode、类型文本、名称、地址、坐标与时间。
- R2 冲突分流：`directory_policy.eligibility` 消费复核结果实现上述矩阵；「TMSF 非住宅 + 高德住宅小区」由直接不收录改为待审核；无复核证据或证据过期时行为与现状完全一致。
- R3 人工用途确认：目录模式下新增受控确认动作（确认含住宅 → 收录、确认非住宅 → 不收录），必填证据（来源类型 + 链接，如克而瑞/房天下/高德）与理由；走 revision 乐观锁与事件审计；人工结果刷新不覆盖；新的相反证据出现时回待审核提示复审；已有人工排除/锁定仍最高优先且不可被绕过或复活。
- R4 存储兼容：复核证据与人工决定附加存储（`amap_position` 同款模式），无 schema 迁移、不回写历史事件；确认只覆盖用途门槛，其余收录门槛照常执行。
- R5 批量任务：复用定位批量任务模式——快照、请求预算上限、间隔限速、取消/中断续跑、网络在事务外、写入前重核资格、取消后不写、按结果而非失败报告、空跑无需 key。
- R6 前端：目录管理页展示高德复核状态与证据；冲突/待确认项有明确待审核入口；确认弹窗必填证据与理由；排除页可发起复核重试。

## 验收
- [x] AC1 离线测试覆盖矩阵全部分支；未找到/查询失败/截断/匹配不确定/取消/预算用尽/断点续跑均不误改判定、不误发布。
- [x] AC2 人工确认：revision 过期 409；确认后刷新、重跑采集、再次批量复核不覆盖；新相反证据回待审核；人工排除/锁定不被绕过、不被自动恢复。
- [x] AC3 兼容：无复核证据时 eligibility 与 catalog 投影和现状一致；存量后端与前端测试全部通过。
- [x] AC4 批量任务：预算/限速/取消/原子发布/取消后不写入；空跑无 key 无上游请求；请求数按配额口径报告。
- [x] AC5 前端：待审核队列、确认流程、证据展示在桌面与 390px 可用；相关组件测试通过。
- [x] AC6 端到端案例：隔离数据上风雅钱塘从 non_residential → 待审核（分类冲突）→ 人工确认含住宅 → admitted，并进入租金/法拍目标集合。
- [x] AC7 spec 更新：directory-flow / directory-position / 新增用途复核契约，明确高德分类「可制造待审核、支撑人工确认、永不自动收录/排除」的新边界。

## 范围外
- 克而瑞/房天下自动采集（本轮仅人工填写证据链接）。
- 不动产登记等官方渠道自动化。
- 新的小区发现来源或全市扫描（复核只针对目录内既有小区）。
- 高德定位绑定（position）逻辑变更。
- 生产数据修正与部署：需用户审阅隔离演练结果后显式执行。
