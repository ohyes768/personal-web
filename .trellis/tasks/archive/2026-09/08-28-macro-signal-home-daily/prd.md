# 宏观信号首页:Tab 置首 + 月度/日频双模式

## Goal

把现有「宏观信号」Tab 提升为宏观页第一个 Tab(首页),并在其内部提供两种时间模式:

- **月度模式**:沿用现有 6 大维度卡片(skill 上传数据),默认显示**上个月**(数据完整月)
- **日频模式**(新增):展示 3 张维度卡片,数据来自系统已有指标序列,默认显示**当日**(A股 15:00 收盘前显示**前一交易日**),支持回看历史交易日

## Requirements

### R1 宏观信号 Tab 置首

- tabs 数组中 `macro-signal` 移到第一位,label 改为「信号首页」
- 页面 `activeTab` 初始值从 `treasury-exchange` 改为 `macro-signal`

### R2 月度/日频分段切换器

- 首页顶部增加「月度 / 日频」胶囊式分段切换器
- 切换器右侧联动显示对应的时间选择器(月份切换器 / 日期切换器)
- 两种模式状态互相独立:切走再切回,月份/日期选择保持

### R3 月度模式(改造现有)

- 复用现有 `MonthSwitcher` + `GroupCardGrid`(6 大维度卡片)
- 默认选中月份从「最新月(含当月)」改为「**上个月**」;若上个月不在 `availableMonths` 中,回退到其中早于当月的最近月份

### R4 日频模式(新增)

- **3 张卡片**,分组与月度维度 key 对齐,复用 `GROUP_META` 标题与色点:

| 维度 key | 卡片标题 | 指标 | 数据来源 |
|---|---|---|---|
| monetary_policy | 货币政策 | DR007 | rates tab `dr007` |
| exchange_rate | 外部压力 | 美元指数、美元兑人民币、TED 利差 | treasury-exchange `exchange_rates.dollar_index` / `usd_cny`,rates `ted_spread` |
| risk_appetite | 市场情绪 | 两市成交额、换手率、融资融券余额 | market-sentiment `volume` / `turnover` / `margin` |

- **指标行内容**:指标名 + 最新值(等宽字体)+ 较前一交易日绝对变化(`▲`/`▼`,红涨绿跌)+ 可跳转曲线 Tab 的「📈」按钮
- **日期规则**:默认当日;本地时间 15:00 前默认前一交易日。所查日期无值的指标行回退显示最近可得值,灰色小字标注实际数据日期
- **日期切换器**:◀ 前一交易日 / 日期下拉(近 60 个交易日)/ 后一日 ▶(不超过当日)
- 卡头无档位刻度(日频无 skill 评分),显示「N 项 · 数据截至 MM-DD」

### R5 后端轻量接口

- 新增 `GET /api/macro/daily-snapshot?date=YYYY-MM-DD`(date 缺省按 15:00 规则取默认)
- 一次请求返回全部 3 组卡片数据 + 可选日期列表,避免前端拉 3 个 tab 全量历史

## Constraints

- 不改动现有月度卡片渲染逻辑与 `/api/macro/signal` 契约
- 日频数据完全复用已有指标序列,不新增抓取任务
- 涨跌颜色遵循 A股习惯:红涨绿跌
- 前端 `basePath=/macro`,本地 dev 走 next.config.js rewrites 代理到 :8094,与现有 fetch 路径约定一致

## Acceptance Criteria

- [ ] 访问宏观页默认落在「信号首页」Tab,且为第一个 Tab
- [ ] 月度模式默认选中上个月;切月、6 卡渲染与改造前一致
- [ ] 月度/日频切换互不清空对方状态
- [ ] 15:00 前访问,日频默认选中前一交易日;15:00 后访问,默认当日
- [ ] 日频 3 卡 7 项指标值与对应曲线 Tab 最新值一致
- [ ] 所选日期无数据的指标行显示回退值并标注实际日期
- [ ] 日频日期可前后逐日切换、下拉回看近 60 个交易日,后一日按钮到当日后禁用
- [ ] `pnpm lint` / `pnpm build` 通过;后端 `pytest` 通过(含新增 daily-snapshot 测试)

## Out of Scope

- 日频模式不展示商品/股指/美债等未列入 3 组的指标
- 不为日频指标做 skill 评分/档位刻度
- 不改定时任务调度
