# 股票基金筛选接入夏普指标（默认≥0.8）

## Goal

股票基金 tab 的筛选条件中接入已有的夏普指标（`fund_risk_metrics.sharpe`，近 3 年口径），默认阈值 ≥ 0.8，让用户能按风险调整后收益过滤基金。

## 背景

- 夏普数据、表格列、排序均已支持（phase2-B 落库），仅筛选条件未接入。
- 股票宇宙 177 只活跃基金：35 只夏普缺失；有值 142 只分布 min=-0.10 / 中位 0.73 / p75=0.90 / max=1.60。
- 默认 ≥ 0.8 时结果约 53 只（含 NULL 被 SQL `>=` 天然排除，与现有 max_dd_3y 筛选行为一致）。

## Requirements

- 后端 `/api/stock/screen` 支持可选参数 `min_sharpe`（≥ 阈值筛选）。
- 前端股票 tab：筛选侧栏新增「夏普」输入项（沿用现有数字输入控件），**默认值 0.8**；chip 栏可展示/清除；URL 参数可携带。
- 债基 tab 完全不动（不加滑条、无默认值）。
- 后端 `_screen` 为两 tab 共享实现，`min_sharpe` 参数自然可用，但债基前端不传即 null。

## Acceptance Criteria

- [ ] `GET /api/stock/screen?min_sharpe=0.8` 只返回 sharpe ≥ 0.8 的基金（NULL 排除）；不传参数行为不变。
- [ ] 股票 tab 页面默认筛选包含夏普 ≥ 0.8，结果与后端直查一致（约 53 只）。
- [ ] 滑条可调整/清除，清除后恢复全量列表；URL 带 `min_sharpe` 参数可复现筛选。
- [ ] 夏普列排序仍然正常。
- [ ] 后端 pytest 通过；前端 `pnpm build` 通过。

## Notes

- 轻量任务，PRD-only。
- sharpe 缺失基金在启用筛选时不可见——已确认为预期行为（与回撤筛选惯例一致）。
