# 宏观图表可读性优化

## Goal

系统检查宏观经济页面各 Tab 的时序图可读性，明确共享图表组件与单图配置的职责边界，使曲线、坐标轴、图例和悬浮读数在桌面端与窄屏下都能清楚辨认。

本任务先完成现状评估与改造方案，未经用户确认不进入实现。

## Background

- 宏观经济页面包含中美利差、流动性/风险、利率、商品、股指、市场情绪和对比等多个图表 Tab。
- 现有图表为时间序列折线图，部分图表包含多条曲线、不同单位或多个 Y 轴。
- 已有按 Tab 独立日期轴的任务，图表可读性改造不能重新把短序列绑定到无关日期轴。
- 用户反馈当前多个 Tab 的曲线图展示效果不好，重点问题是曲线和坐标轴不够清楚。

## Requirements

### R1 现状审计

- 逐个检查各 Tab 的图表组件、Plotly 配置、数据范围、单位、图例、tooltip 和响应式布局。
- 用源码和实际渲染结果区分数据问题、图表配置问题和布局问题。

### R2 组件边界

- 判断是否需要抽取或增强共享图表基础配置。
- 统一跨图表都应一致的视觉规则，例如字体、网格线、轴线、刻度、悬浮提示、图例、边距和响应式行为。
- 保留各图表必须独立定义的语义配置，例如单位、轴数量、轴范围、零线、颜色和序列分组。

### R3 可读性

- 同一图内各曲线可辨认，颜色、线型和标记不能只依赖低对比色差。
- X/Y 轴标题、刻度和单位清楚，不与图例或图形区域重叠。
- 多轴图明确表现每条曲线对应的轴，避免三个以上轴挤压绘图区。
- 商品、股指等 4 至 5 条不同量级序列允许按语义拆成 2 至 3 个共享日期轴的上下联动子图，优先减少叠加 Y 轴数量。
- tooltip 能在同一日期对齐展示相关序列，并按指标单位格式化数值。
- 空值、短序列和数量级差异较大的序列不能导致曲线看似消失。
- 子图 trace 必须同时绑定正确的 X/Y 轴，上下子图共享日期范围并联动缩放。
- tooltip 中的派生值必须预先计算，不能使用 Plotly 不支持的模板算术表达式。

### R4 响应式与兼容

- 桌面端优先保证分析密度，窄屏允许减少刻度、调整图例或分图，但不能裁切关键轴信息。
- 不改变现有数据接口、日期轴语义、更新按钮和 Tab 交互。

## Acceptance Criteria

- [ ] 每个现有图表 Tab 都有问题清单和对应改造项。
- [ ] 明确列出共享组件/配置应负责的内容，以及每个图表单独负责的内容。
- [ ] 桌面宽度下曲线、坐标轴、单位、图例和 tooltip 无遮挡且可辨认。
- [ ] 375px 窄屏下无横向溢出或关键标签裁切。
- [ ] 多单位图不通过简单压缩多个 Y 轴牺牲主要绘图区。
- [ ] 空值、短序列及不同数量级数据有明确可视化策略。
- [ ] 改造不破坏按 Tab 独立日期轴和现有数据加载行为。
- [ ] 利率图中中国 10Y 与中国 10Y-2Y 明确绑定下方子图，不与上方短端利率叠层。
- [ ] 对比图归一化模式正确显示相对起点涨跌，不出现模板字面量或乱码。
- [ ] 中美利差/汇率图从 hidden Tab 首次显示后能自动恢复正确宽度。

## Notes

- 已确认：多单位、多量级场景允许拆成 2 至 3 个共享日期轴的上下联动子图，不强制保持单张叠加图。
