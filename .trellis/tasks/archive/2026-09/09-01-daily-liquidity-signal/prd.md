# PRD:日频流动性卡片(DR001 + DR007 双指标 + 改组名「流动性」)

## 背景与问题

宏观信号页面有月度/日频两个「货币政策」卡片,但口径不同:

- **月度**:`monetary-policy-skill` 三指标加权(DR007 40% + MLF 净投放 30% + LPR 环比 30%),输出 `total_score` + `conclusion`,五档:明显宽松/适度宽松/中性/适度紧缩/明显紧缩。
- **日频**:仅 DR007 单指标原始值 + 日变化,无评分无档位。

同名卡片、两把尺子:用户在月度/日频 tab 间切换时看不到 DR001(隔夜),而 DR001 比 DR007 更贴近当下资金面。日频组命名「货币政策」也不准确——货币政策立场是月频概念,DR 系列反映的是市场资金面。

## 方案(已与用户确认)

日频组改名为**「流动性」**,指标从单 DR007 扩到 **DR001(隔夜)+ DR007(7 天)双指标**,纯数据展示不渲染档位。月度货币政策(三指标加权)完全不动。

**本次不含档位**:用户最终决定不做利差定档、不接 OMO 政策利率。日频「流动性」卡片与日频「汇率」「风险偏好」两个组形态一致——纯数值 + 日变化,无结论、无档位。

## 指标来源

中国货币网质押式回购行情数据(已 demo 验证):

| 数据 | 来源 URL | 用途 |
|---|---|---|
| 当日全期限快照(DR001/DR007/DR014/DR021/DR1M) | `prr-md.json` | DR001 加权利率取自此 |
| DR007 历史日线 | `prr-chrt.csv` | DR007 当日值从最近一行取 |

**DR001 没有公开历史 CSV**——中国货币网只对 DR007 提供滚动日线 CSV,其他期限(DR001/DR014/DR021/DR1M)只有每日快照。因此本次**只展示当日数据,不跳转曲线、不攒历史、不算 MA5**(用户确认)。

## 需求范围

### 后端(backend/macro)
1. **DR001 服务**:新增,数据源 `prr-md.json`,取 `records[productCode='DR001'].weightedRate`(加权利率,与月度 DR007 取加权平均列口径一致)。
2. **DR007 日频取数**:复用现有 `dr007_service.py` 历史接口,只取最近 1 行(当日值)。
3. `daily_snapshot_service.py` 的 `monetary_policy` 组:
   - 指标列表从 `['dr007']` 扩到 `['dr001', 'dr007']`(对齐前端 `DAILY_GROUPS`);
   - 沿用现有 `DailyIndicator` 字段(`key`/`value`/`prev_value`/`data_date`),不引入新字段;
   - **不加档位**:`DailyGroup` 不输出 `conclusion`(与「汇率」「风险偏好」两组一致)。

### 前端(apps/macro)
4. 日频模式该组标题显示「流动性」(月度 tab 标题不动,后端 dimension key `monetary_policy` 不动)。
5. `DAILY_GROUPS` 中 `monetary_policy.indicators` 从 `['dr007']` 改为 `['dr001', 'dr007']`(对齐后端 `_DAILY_INDICATORS`)。
6. **卡头档位刻度不渲染**(本组与汇率/风险偏好一致,纯数据,无档位)。
7. DR001 / DR007 行均无「跳转到曲线图」入口(用户确认)。

## 验收标准

- [ ] 日频模式货币政策组标题显示「流动性」
- [ ] 该组指标显示 DR001 + DR007 双指标:各自当日加权利率 + 日变化 + 数据日期
- [ ] DR001 / DR007 行均无曲线图跳转入口
- [ ] 月度货币政策卡片(标题/档位/评分/DR007 加权 40%)完全不变
- [ ] 后端测试覆盖:`prr-md.json` 拉取失败 / DR001 字段缺失 → DR001 `value` 为 null,DR007 不受影响;`prr-md.json` 整体失败时 DR001 不影响 DR007 取数
- [ ] 日频「流动性」卡片视觉与日频「汇率」「风险偏好」两张卡片完全一致(都是纯数据组)

## 非目标

- 不改月度货币政策评分框架(DR007/MLF/LPR 三指标加权)
- 不改后端 dimension key(`monetary_policy`)与既有 API 路由
- 不攒 DR001 历史 / 不实现 MA5 / 不跳转曲线
- 不引入其他期限(DR014/DR021/DR1M)
- 不渲染档位、不引入 OMO 政策利率、不做利差定档
