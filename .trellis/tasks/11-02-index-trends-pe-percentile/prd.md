# 宽基趋势接入理杏仁沪深300 PE分位

## Goal

在宽基趋势当前页面和每周推送中补充沪深300近10年PE历史分位，帮助用户同时查看趋势位置与估值水平。

## Background

用户已选择理杏仁方案。现有backend/index-trends使用腾讯行情、SQLite存储及周五19:00周报；前端为apps/index-trends。目前没有估值采集。用户本轮授权完成规划，尚未批准进入实施。

## Requirements

- R1：使用理杏仁PE-TTM、总市值加权、近10年分位；直接使用供应商统计值，不在本地重新计算分位。
- R2：页面显示最近完整自然周最后交易日的估值；正常周报与报告周收盘日期对齐。周初显示上一完整周，周五本周结束后显示本周。全周休市时沿用最近有交易完整周并明确日期。禁止引用目标日之后的数据。
- R3：分位为主展示，附PE倍数、实际数据日期、10年窗口、总市值加权口径及理杏仁来源。两个趋势模型共享同一估值，不随模型切换改变口径。
- R4：未配置凭据、无数据、权限不足、请求失败和日期滞后均有明确状态；旧缓存须标记真实日期和异常，不能冒充目标周新值。估值问题不阻断行情、图表与原周报。
- R5：Token仅由后端环境读取，不进入前端响应、日志、数据库或版本库。
- R6：保存估值缓存及报告发送时的估值快照，保持原周报幂等语义。旧报告无需回填；不因PE后续更新重复发送。

## Out of Scope

不接其他数据源、不计算成分股估值、不做本地排名、不加估值历史图/窗口切换/估值交易信号/分位周变化。不改变趋势模型、历史回溯图、原发送时间或渠道。不自动购买理杏仁权限。

## Acceptance Criteria

- [ ] AC1（R1、R3）：指定完整周的PE-TTM及近10年分位在页面和周报一致展示；供应商0–1分位转换成0–100%，分位1位小数、PE2位小数，空值不能显示0。
- [ ] AC2（R2）：周一、周五收盘前后、节假日、全周休市及日历失败均有正确日期或明确异常；不使用未来记录。
- [ ] AC3（R4）：缺Token正常启动；权限、网络、格式和滞后异常可见，原行情刷新与周报仍按既有规则工作。
- [ ] AC4（R5、R6）：凭据不泄露；缓存、迁移、报告快照及已发送报告不重发的检查通过；旧前后端响应兼容。
- [ ] AC5：后端相关测试、前端类型检查和构建通过，375px/1440px检查无溢出，估值与通道百分比含义清楚区分。
- [ ] AC6：真实联调核对沪深300、目标日、账号权限、返回数值及周五更新及时性；没有用户配置的Token时明确记录此项未完成，不宣称生产接入验证成功。
