# 信号首页查看曲线后返回

## Goal

从信号首页点「查看曲线」进入图表 Tab 后，能明确回到信号首页；顶栏直接点进图表的人看不到这条返回。

## 背景

📈 目前只 `setActiveTab`，信号页仍 `hidden` 挂载（月份/日频日期还在）。回来只能再点顶栏「信号首页」。跳转也没走 `handleTabChange`，利率/情绪等 Tab 的默认时间范围不会切。

已选方案 **B**：仅「从信号跳过来」时，在 Tab 描述和图表之间显示 `← 返回信号首页`。

## Requirements

### R1 返回条出现条件

- 信号首页 📈（`onJumpToTab`）进入任一图表 Tab 后出现
- 顶栏直接点进图表 **不出现**
- 跳转后若再用顶栏换别的图表 Tab，**条仍在**
- 回到信号首页后消失（点返回条或点顶栏「信号首页」均可）

### R2 位置与文案

- 只做在 `page.tsx`：Tabs 与图表内容之间一条文字按钮
- 文案：`← 返回信号首页`；不写指标名、不滚动定位到卡片
- 各图表 Tab 不各自加返回按钮

### R3 跳转走 Tab 切换逻辑

有映射的指标行走 `handleTabChange`（含该 Tab 默认时间范围），不要只 `setActiveTab`。信号页继续 hidden 挂载，返回后月份/日频选择还在。

### R4 整行可点

有 `INDICATOR_LINK_MAP` 的月度/日频指标行整行是一个按钮（含数值、日期、📈）。📈 只作视觉提示，不再单独成按钮。无映射的行仍是普通 div，不可点。

## 约束

- 不改 URL / history / 浏览器后退 / Esc
- 不改 📈 的指标映射（`INDICATOR_LINK_MAP`）
- 不改图表读数与信号接口

## 验收标准（Acceptance Criteria）

- [ ] **AC1** 信号首页点击已映射指标的整行（不只 📈），进入对应图表 Tab，内容上方出现 `← 返回信号首页`
- [ ] **AC2** 顶栏直接点「利率利差」等，无返回条
- [ ] **AC3** 从信号跳到利率后再点顶栏「商品」，返回条仍在；点它回到信号首页且条消失
- [ ] **AC4** 返回后信号页月份/日频日期与跳转前一致
- [ ] **AC5** 从信号跳到利率时，时间范围按利率 Tab 规则切到 6M（若当时是 3M/1Y），与顶栏点进利率一致

## 范围外

- 浏览器后退、hash、滚动到指标行
- 对比页从信号跳入（当前无映射，不新增）
