# 已下载音频补标签

## Goal
让 /kids 已下载的 MP3/M4A 在 MA 中按合集组成专辑。

## Requirements
- 仅处理显式指定的目录；默认预览，无写入；支持 --album 限定单个直属合集。
- 按直属合集目录名、NNN-标题文件名推导 album/title/tracknumber。
- 只补缺失；已有 album/title/tracknumber 与推导冲突则整文件跳过。
- albumartist 优先复用合集中唯一的已有 albumartist；否则唯一 artist；再否则“哆咪音频”。已有多个 albumartist 的合集整体报告冲突。
- 艺术家缺失则使用选定 albumartist；已有艺术家不覆盖。不从网络猜测真实创作者。
- 修改前完整备份，备份目录必须位于扫描目录外；支持校验后恢复。
- 不跟随符号链接、不处理 .part；损坏、编号不明及重复曲序报告并跳过。
- 不转码、不移动/重命名音频；重复运行幂等。

## Acceptance Criteria
- [x] MP3/M4A 的预览不改变文件及时间，应用后正确读回五个标签。
- [x] 冲突、损坏、重复曲序跳过；单文件失败不阻断其他文件。
- [x] 音频编码数据保持不变，其他已有标签保留。
- [x] 可恢复为原始字节；恢复拒绝覆盖应用后又被修改的文件。
- [x] 完成 CLI、测试、NAS 使用说明；真实 NAS 执行/MA 重扫验收另行进行。

## Scope
用户已批准“只补缺失、冲突不覆盖”。暂不改下载器、前端、ESP32，不部署或批改 NAS 文件。
