- 浏览器完整交互链路：匹配 → 待确认主页选择 → 更新 → 取消/继续 → 两个动作互斥按钮状态。

### R2 断点粒度加固

当前断点粒度是小区：完成的小区不重跑，处理中的小区被中断后会重查。
需要把进度持久化到「每个搜索通道 / HTTP 步骤」，使中断后从中断点续跑而不是重查。

### R3 独立迁移工具

原规划的独立批量 Fang 迁移预览/应用工具尚未新增（线上 8 个试点是手工通过既有 API 完成的）。
补一个可只读预览、可显式应用、幂等、可按来源恢复、不整库覆盖后续人工操作的迁移工具。

### R4 全量补全上线

- 部署准备完成后核对当前服务任务，备份并执行来源迁移；上线验证无 Fang 网络请求、旧快照不展示、两个任务可启动。
- 小批真实链路验证通过后启动全量批次，报告真实的已检查 / 已关联 / 待确认 / 已采集 / 失败数。
  长时间运行需配置经用户要求的线程后续跟进，**不能以「启动成功」宣称全量完成**。
- 全量幸福里命中率、有效租金覆盖率，以及「莱蒙水榭春天」的位置冲突，需真实数据核对；离线测试不能替代。
