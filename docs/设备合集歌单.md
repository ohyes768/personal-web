# 设备合集歌单

在 `/kids` 下载合集后，点击“生成歌单”。系统扫描 NAS 真实文件，核对 MA 整张专辑的曲目和顺序，按曲目数升序生成连续编号。屏幕使用相同版本的清单与播放映射。

## 配置与首次验证

在 MA 的“设置 → 个人资料（Profile）→ 长期访问令牌（Long-lived access tokens）”中创建一个名为 `kids-catalog` 的令牌并复制。

在 NAS `/home/ohyes768/personal-web/.env` 中配置以下变量，勿提交 token：

```dotenv
KIDS_MA_URL=http://NAS_LAN_IP:8095
KIDS_MA_TOKEN=在MA用户资料页创建的API访问令牌
KIDS_MA_MUSIC_ROOT=/music
```

URL 必须从 kids-catalog 后端容器可达，不要填写容器自身的 localhost。`KIDS_MA_MUSIC_ROOT` 是 MA 内的音频挂载根目录；后端仍使用 `KIDS_MUSIC_DIR=/music`。如果 MA 返回绝对文件路径，系统移除该前缀后进行匹配；相对路径直接使用。支持 MA 2.8.2 的 JSON-RPC 查询接口，未依赖云服务。

部署代码和配置后，在 MA 重扫曲库，先验证一个真实合集是否组成专辑、曲目数正确、按曲序播放。已有音频缺标签时按 [补标签说明](已下载音频补标签.md) 预览、备份后整理；生成歌单不会修改音频文件或自动补标签。新下载的音频如果尚未组成 MA 专辑，同样会报告匹配失败，需要整理后重扫。

参考：[MA API 文档](https://www.music-assistant.io/api/)、[本地文件标签规则](https://www.music-assistant.io/music-providers/local-files/#tagging-files)。NAS 当前实际检查到 2.8.2，API 未认证请求返回 401；本地测试不能代替真实 MA 和设备的播放验收。

## 使用规则

- “下载”与“生成歌单”独立。只有生成成功才更新编号；新增少曲目合集后，重新生成会使已有编号顺延。
- 下载器成功且文件数量核对通过的合集保存独立完成记录。历史 done 下载记录会迁移，候选榜单刷新不会清掉已保存的完成记录与设备清单。
- 无完成记录的历史合集会出现在跳过报告中。确认整套已下载完整后，点击“确认此合集已下载完整”，再生成。该操作是人工声明完整，不能替代核对源平台曲目总数。
- 只计正式 MP3/M4A；封面及附件不计。临时文件、损坏音频、重复或缺失文件名曲序、链接、子目录、文件变化、MA 缺曲或歧义都不会加入清单。
- MA 匹配以本地文件路径、完整曲目集合和曲序为依据，不猜相似名称。优先使用 MA 已有专辑，不创建 MA 播放列表。
- 生成在后台执行，重复点击不会启动并发任务。失败或没有可发布项时保留旧清单。进程中断的生成任务在 15 分钟后允许重试。
- 清单和播放映射持久化在 `/app/data/device_collections.sqlite3`，与候选数据库分离。只保存当前版本。上限为 500 个合集、单名称 256 UTF-8 字节、目录 JSON 128 KiB，超限会明确报告。

## 设备与 HA 接口

经现有 nginx/Next 代理访问；内网直接访问后端时将 `/api/kids/` 改成 `/api/`。

```http
GET /api/kids/device/v1/collections
```

```json
{"schema_version":1,"revision":"opaque-version","generated_at":"2026-10-19T12:00:00+00:00","items":[{"number":1,"title":"唐诗启蒙","track_count":8}]}
```

设备显示“1. 唐诗启蒙（8首）”，开机及周期读取新目录，收到完整合法响应后整体替换。读取失败保留内存旧目录。设备/HA 选择编号时携带当前展示的 revision：

```http
GET /api/kids/device/v1/collections/by-number/1?revision=opaque-version
```

成功响应包含 `revision`、`number`、`title`、`track_count`、`media_type=album`、`ma_media_uri`。将目标交给既有 MA 播放流程，查询本身不会开始播放。

错误 `detail` 含 `code` 和 `message`：404 `directory_missing`/`number_missing`，409 `revision_expired`，503 `target_unavailable`。旧版本必须刷新后让用户重新选择，禁止自动换成新版本同编号。MA 不可达或目标已不可用时拒绝返回可播放结果。

管理接口：`GET /api/kids/collections` 返回 `snapshot` 和 `generation`；`POST /api/kids/collections/generate` 返回 202，后台运行时再请求返回 409；`POST /api/kids/collections/confirm` 请求 `{"folder":"直属合集目录名"}`，非法路径、无效音频或正在下载返回 422。上述接口沿用现有部署访问范围，不向设备返回 MA 凭据和主机路径。

本仓库交付目录服务与管理页面；ESP32 固件替换测试目录、屏幕字段和 HA 调用需在关联工程完成联调。
