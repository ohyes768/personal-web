# 滨江购房地图：市场行情标签页

## 目标

在现有“地图查看”“数据看板”之外新增“市场行情”标签页，展示滨江区及安居客来源页标注的热门商圈挂牌参考行情。它帮助用户理解所看小区的区域市场背景，但不替代透明售房网的网签/成交数据，也不改变既有小区综合评分。

## 已确认的产品决策

- 第一版只交付三项：滨江总览、商圈对比、点击商圈筛选地图。
- 数据语义固定为“挂牌参考”，必须在页面可见位置标明来源与日期；不得称为成交价、签约价或真实成交均价。
- 外部来源仅作人工校验后的月度快照输入；不实现安居客/房天下的自动爬取，不保存其房源明细。
- 价格不参与现有四维综合评分；评分仍只使用现有区位、配套、产品力、市场面数据。

## 界面

### 标签与总览

在现有顶部 tab 末尾新增“市场行情”。内容从上至下为：

1. 标题“滨江市场行情（挂牌参考）”，包含快照月份、来源链接和“非网签成交价”说明。
2. 三张总览卡：滨江挂牌参考均价、环比、同比；用上升/下降箭头配合文字，不仅依赖颜色传达涨跌。
3. 商圈对比表：保留来源页面的热门商圈名、挂牌参考均价、环比和“在地图查看”按钮。来源商圈与地图街道并非同一地理边界：按钮按经过人工标注的街道近似筛选，并逐行显示“非商圈边界”说明；缺失数据显示“暂无参考数据”，不以零补齐。
4. 口径说明：挂牌均价反映当前卖方报价，可能与小区网签成交价不同；数据仅供市场观察。

### 地图联动

点击“在地图查看”时切换到地图标签，设置对应街道近似过滤。地图顶部显示“正在查看：西兴 ×”提示；点击 × 清除该过滤，恢复当前其它筛选条件。该联动不改变搜索词、物业类型和价格口径选择。

## 数据与接口

新增受版本管理的市场参考快照，按如下结构保存：

```json
{
  "source": {"name": "安居客", "url": "https://m.anjuke.com/hz/trendency/binjiangb/", "captured_at": "2026-09-19"},
  "scope": "滨江区",
  "price_kind": "listing_reference",
  "overall": {"avg_price": 38323, "mom_percent": 0.41, "yoy_percent": 3.6},
  "subdistricts": [
    {"name": "彩虹城", "avg_price": 42525, "mom_percent": 1.46, "map_subdistrict": "长河", "map_scope_note": "按长河街道近似查看，非商圈边界"},
    {"name": "西兴", "avg_price": 36488, "mom_percent": 1.8, "map_subdistrict": "西兴", "map_scope_note": "与地图街道一致"}
  ]
}
```

- 后端新增只读 `GET /api/market-reference`，负责读取、验证并返回该快照；缺失或无效时返回空数据与明确状态，不伪造数值。
- 前端首屏加载小区数据的同时加载市场参考数据；接口失败时市场标签显示“暂无市场参考数据”，地图和数据看板保持可用。
- 快照可由维护者月度手工更新；更新时必须同步 `captured_at`、来源 URL 与口径。

## 不在范围内

- 不调用贝壳、安居客、房天下的付费或未授权接口。
- 不做自动爬虫、实时刷新、房源列表或小区“低估/高估”判定。
- 不将挂牌参考价混入地图色阶、数据看板小区均价或综合评分。

## 验收标准

- 新标签可访问，且清楚展示“挂牌参考”“来源”“快照日期”“非成交价”。
- 有数据时正确显示区级卡片和商圈表；无数据/接口失败时仅市场标签降级。
- 点击任一有数据商圈会打开地图并只显示对应商圈；清除过滤后恢复全量地图。
- 现有地图、数据看板、评分与透明售房网价格口径行为不变。
- 后端覆盖正常、缺失和无效快照的接口测试；前端构建与 lint 通过。
