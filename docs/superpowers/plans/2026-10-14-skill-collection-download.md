# 合集完整下载实施计划

**目标：** 合集提供一次完整 ZIP 下载，保留缓存仓库原有说明、路由、全部子 Skill 和公共资源。单项导出保持现有行为。

**方案：** 用已登记 GitHub Skill ID 定位服务端共享仓库缓存，不接收客户端文件路径。新增只读 `GET /api/skills/{skill_id}/collection/download`，快照时复用仓库操作锁，复用确定性 ZIP 构建。保留仓库相对路径，排除 `.git` 和软链，不联网、不改安装或导出台账。根目录无需包含 SKILL.md。

**技术：** FastAPI / pathlib / zipfile；React / TypeScript。

- [x] API 测试先验证根说明、路由、未登记成员、公共文件完整保留；本地 Skill、未知 ID、缓存缺失拒绝。
- [x] 新增下载 API，复用受控缓存解析、快照与打包机制。
- [x] 前端复用 Blob 下载助手，合集操作栏提供独立文字按钮；忙碌防重复、失败提示并允许重试。
- [x] UI 测试验证无需勾选、筛选不裁剪下载范围、单项没有合集下载入口。
- [x] 运行前端类型检查、Lint、测试与 Windows 后端相关测试，按 trellis-check 复核；更新导出契约。不自动提交。
