# 哆咪音频管理功能说明

更新日期：2026 年 10 月 23 日  
页面名称：哆咪的故事库  
访问入口：首页「亲子陪伴」→「哆咪的故事库」，或访问 `/kids`。

哆咪的故事库用于发现适合宝宝的音频专辑、查看内容信息，并将选中的免费音频下载到 NAS，供 xiaomusic 扫描使用。当前内容以 0–1 岁宝宝的儿歌、哄睡及婴幼儿音频为主。

页面顶部有两个页签：「本月精选」是专辑目录与下载，「设备歌单」是生成给设备的播放清单。页签记在网址里（`/kids?tab=playlist`），刷新或分享后仍停在同一个页签。

## 一、页面功能

### 1. 浏览音频专辑（「本月精选」页签）

页面以专辑列表展示当前精选内容，每张专辑可以查看：

| 信息 | 说明 |
| --- | --- |
| 专辑名称 | 点击名称可打开原平台专辑页面 |
| 来源平台 | 显示蜻蜓 FM、喜马拉雅等来源 |
| 年龄依据 | 说明专辑适合宝宝的依据，如平台年龄分类、标题年龄标注或哄睡内容判断 |
| 可信度 | 区分明确年龄依据与内容推断 |
| 付费标识 | 显示免费、会员畅听或付费信息未知 |
| 曲目数量 | 获取到数量时显示，便于了解专辑规模 |
| 文件大小 | 下载后显示已下载文件占用的空间 |
| 下载状态 | 显示下载进度、完成情况或异常原因 |

页面顶部显示精选月份和最近更新时间；尚无内容时，会提示获取最新候选。

### 2. 获取最新内容

点击「获取最新」，可更新候选专辑列表。更新期间显示「正在获取…」，完成后提示本次获取的专辑数量；失败时显示错误提示。

### 3. 下载专辑

点击专辑旁的「下载」，可将整张专辑加入后台下载任务。下载过程中，页面自动更新状态，显示当前处理进度。

| 页面状态 | 含义及可用操作 |
| --- | --- |
| 下载 | 尚未下载，可点击开始 |
| 排队中 | 下载任务已提交 |
| 下载中 | 正在处理专辑曲目，显示当前进度 |
| 已下载 | 全部曲目完成，包含此前已存在的曲目文件 |
| 部分完成 | 部分曲目完成，另有受限或失败曲目；可查看结果说明 |
| 重试 | 下载失败，可点击再次尝试 |
| 付费跳过 | 付费专辑已跳过 |
| 已下架 | 平台已下架该专辑，无法继续下载 |

### 4. 查看结果与返回首页

页面保留当前候选专辑的下载结果，便于查看完成情况、异常说明及文件大小。点击「返回首页」可回到站点入口。

### 5. 生成设备歌单（「设备歌单」页签）

设备歌单是给哆咪设备用的播放清单：按曲目数从少到多编号，设备按编号取到专辑名称再去播放。

| 区域 | 说明 |
| --- | --- |
| 选择要加入歌单的合集 | 列出本月已下载完成的合集，每项显示曲目数，默认全选；可用「全选 / 全不选」一键切换。取消勾选的合集不进入歌单，也不会出现在「未加入歌单的合集」里。勾选状态不保存，重新进入页面恢复全选 |
| 未确认标记 | 完成台账里还没有确认记录的合集会标出「未确认」，生成时以实际文件校验为准 |
| 生成歌单 | 按当前勾选生成；一个都没选时给出提示且不会发起生成 |
| 当前设备歌单 | 显示编号、合集名称与曲目数，以及上次生成时间；重新生成后编号可能调整 |
| 未加入歌单的合集 | 列出生成时被跳过的合集与原因；「未确认下载完整」的合集可点「确认此合集已下载完整」核对后再生成 |

生成时会先检查文件与下载完成记录，再为所选合集补齐缺失的音频标签、更新完成记录并发布设备清单，随后自动通知 Music Assistant（MA）同步本地曲库并核对实际文件归属。

- 标签只补缺失，不覆盖已有歌名、演唱者和人工曲序；曲序优先保留内部标签，其次使用下载文件名中的数字编号，无可靠编号时提示先整理。
- 同一合集的专辑艺术家保持一致；没有可靠信息时使用“哆咪音频”作为整理标识。专辑名称冲突、重复曲序等会明确提示，不能强行覆盖。
- 沿用已确认的不保留完整音频备份方式，采用临时副本、校验和原子替换，并在后端数据卷的 `collection-tag-audit/` 保存处理记录；历史补标签 CLI 的默认备份规则不变。
- “设备歌单已生成”与“MA 已就绪”分别显示。MA 后台扫描真正完成、且目标专辑的曲目与所选目录匹配后，才显示已就绪；MA 未配置、认证失败、同步失败或超时会显示原因，可重新生成重试。
- 生成按钮在补标签和 MA 同步期间保持忙碌。补标签失败的合集会显示“音频信息处理提示”，设备清单仍按既有校验规则发布，但不把 MA 标为就绪。
- MA 网络操作不占用下载数据库写事务；同步期间如果用户删曲、重新下载或本月候选发生变化，最终核对会要求重新生成，不能把旧结果当成已就绪。

生成失败时保留原设备歌单；设备清单发布后发生 MA 同步失败，不回滚已发布编号，页面会明确 MA 尚未就绪。重新生成沿用已补的标签，无须因为工具自身造成的大小/时间戳变化再手工确认完成。

## 二、服务能力

### 1. 汇集宝宝音频资源

- 支持从蜻蜓 FM、喜马拉雅获取候选专辑。
- 支持接入喜马拉雅开放平台内容，需配置相应凭据。
- 以免费儿歌、哄睡及婴幼儿内容为主要收录范围，过滤明确付费的专辑。
- 蜻蜓 FM 公开目录和喜马拉雅网页来源各最多收录 10 张候选，实际数量取决于平台可用内容。
- 为候选提供年龄依据和可信度。部分喜马拉雅内容依据 0–2 岁、0–3 岁标注或婴幼儿哄睡场景推断，并非全部明确标注 0–1 岁。

### 2. 自动与手动更新目录

支持页面手动更新，也支持服务启动时自动获取内容，并在持续运行期间每隔 30 天自动更新。

目录展示最新一轮精选内容。仍在候选中的专辑保留已有下载状态；退出候选列表的专辑及其下载记录不再展示，已下载的音频文件继续保留在 NAS。

### 3. 下载免费音频

- 支持按专辑下载到 NAS，下载在后台进行。
- 支持喜马拉雅 M4A、蜻蜓 MP3 音频。
- 同一专辑重复点击不会重复创建下载任务。
- 再次尝试下载时，可跳过已有的同名曲目文件。
- 整张付费专辑会被跳过；免费专辑中的受限曲目也会跳过。
- 能区分全部完成、部分完成、下载失败和平台下架，并提供结果说明。

### 4. 对接家庭音频库

下载后的音频按专辑分目录存放在 NAS 音乐目录中，供 xiaomusic 扫描使用。页面可查看当前候选专辑下载后的文件占用空间。

## 三、典型使用流程

1. 从首页打开「哆咪的故事库」。
2. 查看已有精选，或点击「获取最新」更新内容。
3. 根据年龄依据、可信度和曲目数量挑选专辑，必要时打开原平台页面查看详情。
4. 点击「下载」，在页面查看进度与结果；失败时可点击「重试」。
5. 下载完成后，通过 xiaomusic 扫描和使用 NAS 中的音频。
6. 到「设备歌单」页签，勾选本次要进入歌单的合集，点击「生成歌单」，设备即可按编号取到专辑名称。

## 四、当前使用范围

当前页面提供候选专辑浏览、内容更新、整张专辑下载、结果查看和设备歌单生成。尚未提供以下功能：

- 页面内试听、播放、播放列表及播放记录。
- 专辑搜索、自定义筛选、收藏及手动导入。
- 单曲选择、批量下载、暂停、取消和删除文件。
- 历史月份目录浏览及完整本地曲库管理。
- 平台账号登录及会员、付费内容下载。
- 歌单内曲目级编辑，勾选只到合集一级。

来源平台的内容可用性会影响采集和下载结果；候选专辑不保证每一首曲目均可下载。

本文按当前项目实现整理，描述已有功能范围，不代表线上服务实时运行状态。
